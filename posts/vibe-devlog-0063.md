# vibe 개발일지 #63 - Claude Code 플러그인 확장과 하네스 안정화 (10개 커밋)

**작업 기간**: 2026-08-14 ~ 2026-08-18

안녕하세요, vibe를 개발하고 있는 Su입니다.

vibe는 **"Easy vibe coding + Minimum quality guaranteed"**를 목표로 하는 AI 코딩 하네스 도구입니다. 에이전트의 지능은 모델이 담당하지만, 모델이 산으로 가지 않고 일관된 품질의 코드를 생산하도록 통제하고 격리하는 것은 온전히 **하네스(Harness)**의 몫입니다.

이번 작업 기간(8월 14일 ~ 8월 18일)에는 Claude Code의 공식 플러그인 생태계 지원과 함께, 내부적으로 발견된 훅(Hook) 시스템의 드리프트 문제와 병렬 실행 시 발생하던 컨텍스트 오염 이슈를 집중적으로 해결했습니다.

## 📝 이번 기간 작업 내용

총 10개의 커밋(5개 PR)을 기능별로 정리해 보았습니다.

### 1. 배포 파이프라인 확장 및 Claude Code 플러그인 지원
- **feat(plugin)**: Claude Code 플러그인 전용 경로 추가 및 배포 트리 동기화 (PR #61)
- **docs**: 3가지 배포 경로(npm, npx, Claude Code Plugin) 문서화 및 릴리즈 게이트 정비 (PR #62)
- 사용자가 어떤 환경에서든 vibe의 스킬과 훅을 즉시 로드할 수 있도록 채널을 3개로 확장했습니다.

### 2. 훅 시스템 정합성 복구 및 업그레이더 개선
- **fix(hooks)**: 플랫폼 내 툴 이름 변경(`Task` → `Agent`, `SlashCommand` → `Skill`)에 따른 텔레메트리/메트릭 0 집계 버그 수정 (PR #64)
- **fix(upgrade)**: 기존 프로젝트 내 복제된 훅 파일이 낡았음에도 `vibe upgrade`가 변경 사항을 감지하지 못하던 감지 로직 수정 (PR #65)

### 3. 하네스 실행 루프(Loop) 격리 강화
- **fix(loop)**: 서브에이전트 간 병렬 파일 쓰기 시 격리(Isolation) 강제 및 검증자(Validator) 컨텍스트의 불변식(Invariant) 명시 (PR #63)

## 💡 작업 하이라이트

### 1. 이름 변경 드리프트(Drift)와 텔레메트리 먹통 해결

최근 Claude Code와 플랫폼 전반에서 용어 정비(`Task` → `Agent`, `SlashCommand` → `Skill`)가 진행되었습니다. 그런데 내부 훅 인터셉터가 과거 툴 이름을 하드코딩 형태로 감시하고 있던 탓에, 스킬 호출 수와 에이전트 실행 통계가 전부 `0`으로 기록되는 웃지 못할 버그가 있었습니다.

```text
[Before]
LLM Event -> Tool: "Skill" -> Hook (Filter: "SlashCommand") -> 누락! (집계 0)

[After]
LLM Event -> Tool: "Skill" | "Agent" -> Hook (정규화 계층) -> 정확한 메트릭 수집
```

단순히 문자열 매칭을 바꾸는 것에 그치지 않고, 상위 플랫폼의 툴 명칭 변경에 유연하게 대응할 수 있도록 매핑 어댑터를 두었습니다. 또한 프로젝트 로컬에 복사되어 있던 구버전 훅 스크립트들을 `vibe upgrade` 시 해시 비교를 통해 안전하게 최신화하도록 업그레이드 로직을 보강했습니다.

### 2. 병렬 에이전트 실행 시의 불변식 보장

`/vibe.run` 단계에서 여러 하위 에이전트가 동시에 컴포넌트와 테스트를 작성할 때, 드물게 공유 컨텍스트가 오염되거나 검증자가 중간 상태를 완결 상태로 오인하는 레이스 컨디션이 있었습니다.

- **병렬 쓰기 격리**: 각 작업 단위별로 독립된 가상 파일시스템 버퍼를 강제하고, 작업 완료 후 메인 브랜치로 머지하는 방식 적용
- **검증자 불변식(Invariant)**: 검증자(Validator)가 코드를 평가할 때는 외부의 비동기 쓰기가 완전히 락(Lock)되도록 상태 머신 수정

이로써 아무리 복잡한 병렬 작업이라도 "검증을 통과한 코드만 남는다"는 하네스의 기본 품질 보증 원칙을 지킬 수 있게 되었습니다.
