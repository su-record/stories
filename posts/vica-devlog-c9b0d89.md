# vica 개발일지: Claude 별칭과 버전 표시 정리, git 기록 팝업 시안

2026년 11월 11일의 vica 커밋 3개는 모델 관리와 git 기록 화면이라는 두 영역으로 묶을 수 있습니다. 모델 쪽에서는 Claude 별칭이 새 버전을 따라가도록 수정하고, 화면에서도 버전을 볼 수 있게 했습니다. 이 변경과 관련한 코드 사실을 지식 문서에 남기는 작업도 함께 진행했습니다. git 기록 쪽에서는 팝업 시안을 테마 14종으로 그렸습니다. 이번 일지는 제공된 커밋 설명을 기준으로, 구현 변경과 문서·디자인 작업을 구분해 정리합니다.

## 모델 관리: 별칭 갱신과 버전 표시를 함께

Claude 모델 변경의 핵심은 별칭이 새 버전을 따라가게 하는 동작과, 그 버전을 화면에 보여 주는 표시를 함께 다뤘다는 점입니다. 별칭으로 모델을 선택하는 방식은 유지하면서도 어떤 버전인지 확인할 수 있도록 손본 셈입니다.

별칭은 모델을 부르는 이름이고, 버전은 그 이름이 가리키는 대상을 구체적으로 확인하는 정보입니다. 이번 수정에서는 두 정보의 관계가 중요합니다. 별칭이 새 버전을 따라가더라도 화면에서 버전을 알 수 없다면 사용자가 변경을 알아보기 어렵습니다. 버전 표시를 함께 수정한 것은 이런 확인에 필요한 정보를 화면에 제공한다는 의미가 있습니다.

다만 커밋 설명만으로는 별칭이 가리키는 정확한 버전 번호나 갱신 방식을 알 수 없습니다. 화면의 어느 위치에 어떤 형식으로 버전을 표시하는지도 확인되지 않습니다. 따라서 이번 변경을 별도의 자동 업데이트 체계를 구축한 작업이나 모든 모델의 버전 표시를 통일한 작업으로 확대해 설명하지는 않겠습니다. 확인할 수 있는 범위는 Claude 별칭의 동작과 화면 표시를 수정했다는 데까지입니다.

### 변경에 관한 코드 사실도 문서로

모델 관리 영역에는 지식 문서 작업도 포함됩니다. 모델 별칭 갱신과 관련한 코드 사실을 기록해, 구현 변경을 문서에서도 다뤘습니다. 기능 수정과 같은 날짜에 해당 내용을 기록했다는 점에서 함께 살펴볼 작업입니다.

이 문서의 역할은 별칭 갱신에 관해 코드로 확인한 내용을 남기는 데 있습니다. 이후 관련 동작을 살펴볼 때 참고할 기록이 생긴 것이죠. 다만 문서 본문은 제공되지 않았으므로 어떤 함수나 설정을 근거로 삼았는지, 예외 조건까지 정리했는지는 여기서 단정할 수 없습니다. 문서가 추가됐다는 사실과 문서의 상세한 검증 범위는 구분해 두겠습니다.

## git 기록 화면: 테마 14종으로 팝업 시안 작성

git 기록 영역에서는 팝업 디자인을 테마 14종으로 그렸습니다. 하나의 팝업을 여러 테마로 살펴볼 수 있는 시안을 마련한 작업입니다. 모델 영역이 동작과 표시를 수정한 구현 작업이라면, 이쪽은 화면의 모습을 검토하기 위한 디자인 문서 작업에 해당합니다.

여러 테마의 시안은 같은 정보를 서로 다른 시각적 조건에서 비교하는 자료가 될 수 있습니다. 다만 14종을 그렸다는 사실만으로 가독성 검증을 마쳤다거나 최종 디자인을 확정했다고 볼 수는 없습니다. 실제 팝업에 어떤 항목이 들어가는지, 테마별로 무엇이 달라지는지도 커밋 설명에는 나와 있지 않습니다.

특히 이번 기록은 시안 작성이므로, git 기록 팝업이 제품에 구현됐다고 소개하지 않도록 구분해야 합니다. 현재 확인되는 결과물은 테마 14종의 디자인 시안입니다. 실제 화면 반영 여부와 상호작용 구현은 별도로 확인할 사항으로 남습니다.
