# vica 개발일지: 저장소 클론 진입점과 데스크톱 첫 화면 정리

2026년 11월 5일의 vica 작업은 프로젝트 메뉴, 데스크톱 표시, 스크립트 정리로 나눌 수 있습니다. 프로젝트를 다루는 두 곳에 저장소 클론을 추가했고, 앱을 켤 때 잠깐 보이던 어두운 테마와 아이콘 표시를 손봤습니다. 라야 튜닝 스크립트 폴더도 삭제했습니다. 이번 기록에서는 네 커밋을 기능과 영역별로 묶어 소개해 보겠습니다.

## 프로젝트 메뉴에서 저장소 클론 시작하기

프로젝트의 `+` 메뉴와 프로젝트 목록의 우클릭 메뉴에 저장소 클론을 추가했습니다. 이제 두 메뉴에서 클론 작업을 시작할 수 있습니다.

두 진입점은 같은 기능을 서로 다른 맥락에서 꺼낼 수 있게 해 줍니다. `+` 메뉴는 프로젝트를 추가하려고 할 때, 목록의 우클릭 메뉴는 프로젝트 목록을 살펴보던 중에 접근할 수 있는 자리입니다. 저장소를 가져오려는 사용자가 어느 쪽 메뉴를 열더라도 클론 항목을 찾을 수 있도록 접점을 늘린 변경입니다.

여기서 소개할 범위는 클론 기능의 **메뉴 진입점 추가**까지입니다. 인증 방식이나 클론 진행 화면, 완료 후 처리에 관한 내용은 이번 커밋 정보에 없습니다. 클론 과정 전체가 달라졌다고 설명하기보다는, 프로젝트 화면에서 해당 작업을 시작할 수 있는 위치가 늘었다고 보는 것이 정확하겠습니다.

## 앱 시작 시 테마와 아이콘 표시 손보기

데스크톱에서는 앱을 처음 열 때 보이는 모습을 정리했습니다. 먼저 어두운 테마가 잠깐 나타났다가 바뀌는 현상을 수정했습니다. 시작 직후의 화면도 사용자가 보는 앱의 일부인 만큼, 최종 화면뿐 아니라 그 화면이 나타나기까지의 표시도 수정 대상에 포함했습니다.

이번 테마 수정의 초점은 새로운 색상이나 테마 선택지를 제공하는 데 있지 않습니다. 앱이 켜지는 순간 먼저 표시되던 어두운 테마 때문에 화면이 한 차례 바뀌어 보이는 문제를 다뤘습니다. 다만 어떤 초기화 순서나 설정을 바꿨는지는 제공된 기록에 없으므로, 구현 방식까지 추측해 적지는 않겠습니다.

아이콘도 함께 손봤습니다. 앱 아이콘이 판 없이 그려지도록 바꾸고, 아이콘을 덮어쓰던 사용자 지정 아이콘을 제거했습니다. 아이콘 자체의 표시 형태와 이를 덮어쓰는 요소를 함께 정리한 작업입니다.

테마와 아이콘 수정은 모두 데스크톱에서 vica가 어떻게 보이는지에 관한 변경이지만, 다루는 문제는 다릅니다. 테마 쪽은 앱 시작 시 화면이 바뀌는 현상이고, 아이콘 쪽은 그려지는 형태와 덮어쓰기 문제입니다. 화면 표시를 손봤다는 공통점 아래에서도 각각의 수정 범위는 구분해 두었습니다.

## 라야 튜닝 스크립트 폴더 삭제

저장소 내부에서는 라야 튜닝 스크립트 폴더를 삭제했습니다. 앞선 작업들이 메뉴나 화면에 드러나는 변경이라면, 이 작업은 저장소에 남겨 두는 파일의 범위를 정리한 변경입니다.

삭제 이유나 대체 도구는 커밋 정보만으로 확인할 수 없습니다. 따라서 더 이상 사용하지 않는다고 단정하거나, 다른 튜닝 절차로 이전했다고 설명할 근거는 없습니다. 이번 개발일지에는 해당 스크립트 폴더를 제거했다는 사실까지만 남깁니다.

이번 네 커밋에서 사용자가 직접 확인할 부분은 프로젝트 메뉴의 클론 항목, 시작 시 테마 표시, 앱 아이콘입니다. 저장소 내부의 스크립트 삭제는 별도 정리 작업으로 구분했습니다. 메뉴에 무엇을 더했는지와 기존 표시에서 무엇을 고쳤는지를 나눠 보면, 이번 변경의 범위를 조금 더 명확하게 살펴볼 수 있습니다.
