# vica 개발일지: Chat 중심의 작업 흐름과 터미널 기록 정리

2026년 10월 29일의 최근 커밋 15개는 Chat에서 일을 맡기고, 진행 중인 작업과 지난 기록을 다시 확인하는 흐름에 집중했습니다. 역할별 모델에게 작업을 맡기는 기능부터 앱 재시작 뒤 상태 복원까지 연결했고, 터미널은 기록을 읽고 창 크기를 바꾸는 기본 동작을 손봤습니다. 기능이 추가되는 동안 화면 구성도 바뀌어서, 이번 일지는 최종적으로 달라진 흐름을 중심으로 정리해 보겠습니다.

## Chat에서 작업을 맡기고 대화를 이어갑니다

Chat 탭에는 vica가 역할별 모델에게 일을 맡기고 답하는 기능을 넣었습니다. 여기에 ‘vica 지능 스펙’ 20절을 구현하고, 설계 문서에도 결과 판정·빠른 답·미리 찾기를 명시했습니다. 작업을 위임하는 기능과 그 결과를 다루는 기준을 코드와 문서 양쪽에 반영한 셈입니다. 다만 커밋 정보만으로 응답 품질이나 처리 속도가 얼마나 달라졌는지까지 말하기는 어렵습니다.

대화를 오가는 화면도 함께 다듬었습니다. Chat에 새 대화 버튼을 추가했고, Chat 맵은 Codex 앱과 비슷한 구성으로 바꿨습니다. 이미지·파일 아이콘도 더했습니다. 한편 터미널 맵은 최종 변경에서 제거했습니다. 앞선 커밋에는 세션 맵 이동과 동작 개선이 포함돼 있지만, 이번 변경을 소개할 때 터미널 맵이 그대로 남아 있다고 설명하지 않도록 구분할 필요가 있습니다.

## 재시작 뒤에도 작업 맥락을 이어갑니다

vica를 재시작해도 백그라운드 실행을 이어받도록 했고, 창과 대화 상태를 복원하는 기능도 넣었습니다. 백그라운드 작업의 실행을 이어받는 것과 사용자가 보던 화면을 되돌리는 것은 서로 다른 부분이라, 이번에는 두 영역을 함께 다뤘습니다.

작업 기록 화면도 추가했습니다. 현재 대화뿐 아니라 이전 작업을 확인할 자리가 생긴 것입니다. 다만 어떤 상태까지 복원하는지, 작업 기록에 무엇을 얼마나 보관하는지는 제공된 커밋 요약에 드러나지 않습니다. 그래서 “모든 작업이 완벽하게 복구된다”는 식으로 범위를 넓혀 설명하지는 않겠습니다.

## 터미널은 지난 출력을 읽는 동작부터 손봤습니다

터미널 쪽에서는 스크롤백을 추가하고, 기록을 브라우저 스크롤로 읽도록 바꿨습니다. Codex 실행에는 `--no-alt-screen` 옵션을 적용했습니다. 터미널 기록 응답이 브리지를 통과하면서 망가지는 문제도 수정해, 기록을 보여주는 화면뿐 아니라 데이터를 전달하는 경로까지 손봤습니다.

전체 화면 프로그램을 실행할 때의 입력 문제도 다뤘습니다. Codex 같은 프로그램 안에서도 휠과 당시의 세션 맵이 동작하도록 수정했습니다. 이는 이후 터미널 맵을 제거한 화면 구성 변경과는 별개의 수정입니다.

창 크기와 터미널 크기의 관계도 정리했습니다. 창을 조절하면 터미널이 바로 따라오게 했고, 아무도 보고 있지 않은 탭의 터미널은 마지막 크기를 유지하도록 데몬을 수정했습니다. 보고 있는 창에는 크기 변경을 즉시 반영하고, 보지 않는 탭에는 기존 크기를 남기는 방식입니다.

## 배포와 연결 기반도 보강했습니다

데스크톱에는 3개 언어 지원과 클론·업데이트 기능을 더하고, vica 캐릭터를 앱 아이콘으로 적용했습니다. 작업 화면 외에 앱을 사용하고 관리하는 주변 기능도 함께 확장했습니다.

연결 영역에서는 vica 전용 중계 서버인 `vica.torylabs.dev`를 만들었습니다. 중계 관련 문서의 시험 실행 명령도 Node 22에서 동작하도록 고쳤습니다. 서버 추가와 실행 안내 수정을 함께 반영했지만, 운영 안정성이나 성능을 확인할 수 있는 수치는 이번 자료에 없습니다.

이번 변경으로 Chat의 작업 위임, 재시작 뒤 실행과 화면 복원, 터미널 기록 확인까지 다루는 범위가 넓어졌습니다. 실제 사용에서도 이 흐름이 끊기지 않는지는 별도로 확인해야 합니다. 특히 상태 복원과 터미널 기록은 기능 추가 여부만큼이나, 여러 실행 상황에서 같은 동작을 유지하는지가 중요한 확인 지점입니다.
