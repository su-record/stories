# vica 개발일지: 채팅과 화면의 작은 어긋남을 고쳤습니다

11월 25~26일의 최근 커밋 10개는 채팅과 에이전트 실행, 모델 설정, macOS 사용 환경을 다듬는 작업에 집중됐습니다. 조사부터 발표 자료 작성까지 이어지는 발표 모드 시안도 문서로 남겼습니다. 이번에는 실제로 고친 동작과 기록·설계에 머문 내용을 나눠 정리해 보겠습니다.

## 채팅에 시각을 알리고, 불필요한 도구 호출 줄이기

채팅에서는 메시지를 보낸 시각을 알리도록 했습니다. 또 답에 필요한 내용이 이미 요청 안에 있으면 도구를 쓰지 않고 답하도록 조정했습니다. 요청에 담긴 정보만으로 처리할 수 있는 경우까지 도구를 거치지 않게 하려는 변경입니다.

도구 사용을 무조건 줄이는 방향은 아닙니다. 이번 변경의 기준은 ‘답이 요청 안에 있는가’입니다. 별도 확인이 필요한 질문까지 같은 방식으로 처리한다고 볼 수는 없습니다. 응답 시간이나 호출 횟수가 얼마나 달라졌는지는 이번 커밋 목록만으로 말씀드리기 어렵습니다.

자체 AI가 질문할 때 실행 번호를 잃던 문제도 고쳤습니다. 질문과 해당 실행을 이어 주는 정보를 유지하는 수정입니다. 채팅에서 보이는 답변뿐 아니라, 그 질문을 처리하는 실행의 연결도 함께 손봤습니다.

## 모델이 만든 화면과 모델 선택 목록 정리

A2UI에서는 모델이 흔히 잘못 만드는 화면 JSON을 그리기 전에 바로잡도록 했습니다. 모델 출력물을 화면으로 옮기기 직전에 보정하는 단계가 생긴 셈입니다. 다만 어떤 오류 유형까지 보정하는지는 커밋 메시지에 드러나지 않으므로, 모든 잘못된 JSON을 처리한다고 설명할 수는 없습니다.

설정의 모델 목록도 선택 기준을 다듬었습니다. API 키로 호출할 수 있는 모델은 모두 보여 주되, 로그인 방식에 있는 모델은 제외하도록 했습니다. 키로 쓸 수 있는 모델이 빠지지 않게 하면서, 로그인 쪽과 겹치는 항목을 정리한 변경입니다. 모델을 고를 때 목록에 무엇이 포함되는지에 관한 규칙을 손본 작업으로 묶을 수 있겠습니다.

## macOS에서 첫 클릭과 개발 앱 설치 수정

뒤에 있던 앱 창을 처음 눌렀을 때 단추도 동작하도록 고쳤습니다. 창을 앞으로 가져오는 첫 클릭이 단추 누르기로도 이어지게 한 것입니다. 눈에 띄는 기능 추가는 아니지만, 창을 오가며 사용할 때 직접 마주치는 동작을 다룬 수정입니다.

개발 앱 설치 스크립트에서는 다른 계정이 만든 앱 폴더에도 설치할 수 있게 했습니다. 이번 수정은 앱 폴더를 만든 계정이 다른 경우를 대상으로 합니다. 이를 macOS의 모든 설치 권한 문제를 해결한 것으로 넓혀 말하지는 않겠습니다.

배포 관련 문서도 함께 맞췄습니다. README의 내려받기 안내를 macOS 0.2.5로 갱신했고, 지식 문서에는 맥 0.2.5 합류와 그 뒤 새로 낼 것이 없었던 배포 요청을 기록했습니다. 내려받기 안내를 바꾸는 작업과 배포 경위를 남기는 작업을 각각 진행했습니다.

## 실측 기록과 발표 모드 시안

지식 문서에는 Solar Mini 4.5 Preview의 실측과 수정한 내용을 남겼습니다. 이번에 받은 목록에는 측정 수치나 구체적인 수정 항목이 없어 성능에 대한 결론을 덧붙이지 않았습니다. 여기서 확인할 수 있는 범위는 실측과 수정 내용을 문서화했다는 점까지입니다.

발표 모드는 조사부터 발표 자료를 만드는 과정까지 담은 시안을 작성했습니다. 아직 이번 목록에서 확인되는 것은 설계 문서이며, 사용할 수 있는 기능으로 구현됐다고 소개할 단계는 아닙니다.

이번 작업은 첫 클릭, 모델 목록, 화면 JSON처럼 사용 중 어긋날 수 있는 지점을 고치는 데 무게가 실렸습니다. 발표 모드는 시안으로, 실측과 배포 경위는 기록으로 남겼습니다. 구현한 동작과 검토 중인 구상을 구분해 두는 것까지 이번 개발일지에 담았습니다.
