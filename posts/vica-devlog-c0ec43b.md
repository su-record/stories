# vica 개발일지: 채팅 화면 공유와 재시작 복원, 메일·캘린더 직접 연결

2026년 11월 24일의 최근 커밋 7개는 채팅 화면 부품을 데스크톱과 휴대폰에서 사용하는 작업, 재시작 뒤 응답 상태를 복원하는 작업, 메일·캘린더 연결을 중심으로 묶을 수 있습니다. 윈도에서 연결용 비밀을 저장하는 기능도 추가했고, 조사 내용과 0.2.4 배포 계획을 문서에 남겼습니다.

## 데스크톱과 휴대폰이 같은 채팅 화면 코드를 씁니다

데스크톱에서는 채팅 화면 부품이 실제로 쓰이도록 연결했습니다. 휴대폰에서도 이 부품을 컴퓨터와 같은 코드로 그리도록 바꿨습니다. 이번 변경으로 두 환경이 채팅 화면을 그리는 코드를 공유하게 됐습니다.

코드를 공유하면 화면 부품을 수정할 때 두 환경을 함께 살펴볼 기반이 생깁니다. 다만 같은 코드를 쓴다는 사실만으로 화면 크기나 입력 방식에 따른 차이까지 모두 해결됐다고 볼 수는 없습니다. 이번 기록에서 확인할 수 있는 범위는 데스크톱의 실제 사용 경로에 부품을 연결했고, 휴대폰도 공통 코드로 그리게 됐다는 점입니다.

## 다시 켜도 답한 상태를 이어갑니다

데스크톱의 채팅 화면에서는 이미 답한 내용을 재시작 뒤 어떻게 보여줄지도 손봤습니다. 먼저 답변을 마친 화면이 앱을 다시 켜도 잠긴 상태를 유지하도록 했습니다. 여기에 답한 양식의 값을 되살리는 작업을 더했습니다.

두 변경은 역할이 조금 다릅니다. 잠금 상태는 이미 응답을 마친 화면이라는 상태를 보존하고, 값 복원은 그때 입력했던 내용을 다시 보여줍니다. 잠금만 남고 입력값이 사라지거나, 값은 보이는데 응답 완료 상태가 풀리는 일을 각각 다루는 변경입니다. 재시작 이후의 화면을 복원할 때 입력 내용과 응답 상태를 함께 다루게 됐습니다.

그리지 못한 화면은 같은 모델이 다시 그리도록 처리했습니다. 화면을 그리는 데 실패했을 때의 후속 경로를 마련한 셈입니다. 다만 커밋 정보에는 재시도 횟수나 복구 성공률이 없어서, 모든 렌더링 실패를 해결했다고까지 말하기는 어렵습니다.

## 메일·캘린더에 직접 연결하고, 윈도 금고에도 비밀을 저장합니다

비카가 메일과 캘린더에 직접 연결하는 기능을 데스크톱에 추가했습니다. 이와 함께 윈도에서도 메일·캘린더 연결에 쓰는 비밀을 금고에 저장할 수 있게 했습니다. 서비스 연결과 연결 정보 보관을 같은 날 함께 다룬 작업입니다.

여기서 확인되는 변화는 직접 연결 경로와 윈도의 비밀 저장 지원입니다. 어떤 메일·캘린더 제공자를 지원하는지, 연결에 어떤 권한이 필요한지는 주어진 커밋 정보에 포함돼 있지 않습니다. 그래서 이번 일지에서는 지원 범위를 넓혀 설명하지 않고, 구현한 연결과 저장 기능까지만 정리합니다.

## 조사 기록과 0.2.4 배포 범위도 맞췄습니다

지식 문서에는 윈도 카카오톡 저장 파일을 조사한 내용과 라야 제거 상태를 기록했습니다. 이 변경은 기능 추가와 구분해서 볼 필요가 있습니다. 저장 파일을 조사했다는 기록을 곧바로 가져오기 기능 지원으로 읽거나, 제거 상태를 기록했다는 이유만으로 제거가 완료됐다고 단정하지는 않겠습니다.

0.2.4 릴리스 노트에는 채팅·휴대폰 화면 부품을 추가하고, 중계를 0.2.4와 함께 배포한다고 명시했습니다. 최근 구현 내용과 배포 계획을 문서에서 확인할 수 있도록 맞춘 것입니다. 중계의 실제 배포 완료 여부와는 구분되는 계획 기록입니다.

이번 작업에서는 새 연결 기능을 추가하는 한편, 이미 답한 화면을 다시 열었을 때의 상태도 챙겼습니다. 특히 채팅 화면은 공통 코드 사용과 재시작 복원이 함께 진행됐습니다. 이후 사용성을 살필 때도 두 기기에서 화면이 그려지는지와, 데스크톱 재시작 뒤 답변 값과 잠금 상태가 함께 유지되는지를 나눠 확인할 수 있겠습니다.
