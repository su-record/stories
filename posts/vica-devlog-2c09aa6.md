# vica 개발일지: API 키 확인부터 영상 분석, 채팅 화면 안정화까지

2026년 11월 12일의 최근 커밋 18개에서는 API 키 설정과 모델 선택, 판단 엔진, 영상 분석, 채팅 화면을 손봤습니다. 새 모델을 추가하는 작업과 함께, 입력한 키가 사라지거나 응답 없는 요청 때문에 분석이 멈추는 문제도 고쳤습니다. 기능별로 무엇이 달라졌는지 정리해 보겠습니다.

## API 키로 쓸 수 있는 모델을 확인합니다

설정 화면에서는 입력한 API 키가 지워지지 않도록 고치고, 저장하거나 지운 결과가 바로 화면에 보이게 했습니다. 키를 다루는 화면인 만큼 입력한 값과 저장 상태를 확인할 수 있어야 하는데, 이번에는 그 기본 동작부터 정리했습니다.

모델 선택도 키를 기준으로 바꿨습니다. 테스트 버튼을 누르면 해당 API 키로 사용할 수 있는 모델을 확인해 표시합니다. 이어서 그 키로 쓸 수 있는 최신 모델을 확인하고 선택할 수 있도록 연결했습니다. 모델 목록을 보여 주는 데서 그치지 않고, 입력한 키로 무엇을 쓸 수 있는지 설정 과정에서 확인하게 한 변화입니다.

Gemini 키 연결에서는 테스트, 도구 호출, 로그인 표시를 수정했습니다. 다만 이번 커밋 목록만으로 모든 키와 모델 조합을 검증했다고 말할 수는 없습니다. 키별 모델 실측과 무료 키 한도 조사 기록도 갱신했지만, 구체적인 지원 범위나 한도 수치는 여기서 단정하지 않겠습니다.

## 판단 엔진의 선택지와 키 사용 기준을 정리했습니다

판단 엔진에는 Google 판단 모델인 `gemini-decision-1`을 추가했습니다. GPT 판단 쪽에서는 설정에 저장한 OpenAI 키를 먼저 사용하도록 우선순위를 고쳤습니다. 사용자가 설정한 키와 실제 판단 요청에 쓰이는 키가 어긋나지 않도록 하는 수정입니다.

판단 엔진 측정과 키별 모델 기록도 함께 갱신했습니다. 이번 변경에서 확인할 수 있는 것은 판단 모델의 선택지가 늘고 키 사용 기준이 정리됐다는 점입니다. 모델 간 정확도나 속도의 우열까지 설명할 측정값은 제공된 커밋에 없습니다.

## 영상 분석 결과를 보관하고, 멈춘 요청을 넘깁니다

영상 분석에는 결과를 지식에 쌓고 사용한 토큰을 집계하는 기능을 넣었습니다. 분석 결과를 남기는 일과 분석에 쓴 토큰을 세는 일을 함께 추가한 셈입니다. 토큰 집계가 들어갔다고 해서 비용 계산까지 구현됐다는 뜻은 아니므로, 이번 변경의 범위는 구분해서 봐주시면 좋겠습니다.

응답 없는 요청에 영상 분석이 붙잡히는 문제도 수정했습니다. 해당 요청에서 멈춰 있지 않고 다음 모델로 넘어가도록 했습니다. 모든 분석의 성공을 보장하는 변경은 아니지만, 응답하지 않는 요청 하나가 이후 진행을 막는 상황을 다뤘습니다. 영상 분석 실측과 보관 관련 기록도 함께 정리했습니다.

## 채팅 화면이 밀리거나 비는 문제를 줄였습니다

채팅에서는 그림이 들어갈 자리를 미리 확보해, 시작할 때 스크롤이 밀리지 않도록 했습니다. 마우스를 올린 요소가 화면을 다시 그릴 때마다 새로 만들어지는 문제도 고쳤습니다. 스크롤 위치와 마우스를 올린 상태처럼, 내용을 읽거나 조작하는 동안 영향을 주는 부분을 손봤습니다.

표를 그리는 과정에서는 머리줄보다 데이터 칸이 많은 경우 채팅 전체가 비는 문제를 수정했습니다. 작업 중 머리줄에는 회사 아이콘을 표시하고, 진행 줄이 반복해서 나타나는 현상도 없앴습니다. 화면의 장식보다는 내용 표시와 진행 상태를 안정적으로 유지하는 데 초점을 둔 작업입니다.

다시 그리기와 툴팁 규칙, 표 그리기 등 관련 기록도 갱신했습니다. 이번 작업은 새 선택지를 더하는 한편, 설정과 분석, 화면 표시 사이에서 끊기던 동작을 고치는 데 무게가 실렸습니다. 성능 개선 폭을 숫자로 제시할 근거는 없지만, 어떤 조건에서 문제가 생겼고 무엇을 바꿨는지는 구분해 남겼습니다.
