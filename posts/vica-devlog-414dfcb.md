# vica 개발일지: 채팅 화면 정리와 컴퓨터 조작 대상 확장

2026년 11월 11일의 vica 작업은 채팅 화면을 정리하고, 컴퓨터 조작 기능의 범위를 넓히는 데 집중됐습니다. 채팅에서는 입력창 위 줄에서 최근 모델을 빼고 끊김 알림이 스스로 닫히도록 바꿨습니다. 컴퓨터 쪽에는 앱 상태 확인, 화면 글자 조작, 파일 놓기와 실제 휴대폰 대상을 추가했습니다. 이번 글에서는 최근 커밋 3개를 사용 화면, 조작 기능, 릴리스 준비로 나눠 정리합니다.

## 채팅: 입력창 주변 표시와 알림 동작 정리

채팅 입력창 위 줄에서는 최근 모델 표시를 제거했습니다. 이번 변경의 범위는 해당 줄에 무엇을 보여 주느냐에 있습니다. 모델 선택 기능 자체를 없앴다는 뜻은 아니므로, 최근 모델 기능 전체가 사라졌다고 설명하지는 않겠습니다.

끊김 알림은 스스로 닫히도록 수정했습니다. 연결 문제를 알리는 역할은 유지하면서, 알림이 화면에 남는 방식을 바꾼 작업입니다. 다만 제공된 커밋 정보에는 자동으로 닫히는 시간이나 구체적인 조건까지 담겨 있지 않습니다. 따라서 “몇 초 뒤 사라진다”거나 “연결이 복구되면 닫힌다”고 단정할 수는 없습니다.

두 변경은 모두 채팅 화면에 표시되는 정보와 관련이 있지만, 손본 지점은 다릅니다. 최근 모델은 표시 위치의 구성을 바꿨고, 끊김 알림은 표시 이후의 동작을 바꿨습니다. 대화 기능을 새로 더하기보다는 입력창 주변과 알림의 사용 흐름을 다듬은 작업으로 묶을 수 있겠습니다.

## 컴퓨터: 상태 확인부터 조작 대상 확대까지

컴퓨터 영역에는 앱 상태를 확인하는 기능이 추가됐습니다. 조작 기능과 함께 현재 앱의 상태를 확인하는 항목도 생긴 셈입니다. 다만 어떤 상태를 구분하고 어떤 형식으로 결과를 제공하는지는 커밋 메시지만으로 확인하기 어렵습니다. 이번 기록에서는 앱 상태 확인이 추가됐다는 범위까지만 다룹니다.

화면 글자 조작과 파일 놓기도 새로 들어왔습니다. 화면의 글자를 다루는 작업과 파일을 놓는 작업이 컴퓨터 기능에 포함됐다는 점이 이번 변화입니다. “화면 글자 조작”이라는 표현만으로 글자 인식 방식이나 선택·입력의 세부 동작을 확정할 수는 없습니다. 파일 놓기 역시 지원 위치나 파일 형식에 관한 정보가 없어, 모든 앱에서 같은 방식으로 사용할 수 있다고 소개하기는 이릅니다.

조작 대상에는 실제 휴대폰이 추가됐습니다. 이 부분은 조작 항목을 늘린 변경과 구분해서 볼 만합니다. 앱 상태 확인, 화면 글자 조작, 파일 놓기가 수행할 수 있는 작업에 관한 내용이라면, 실제 휴대폰 추가는 작업을 적용할 대상의 확장입니다. 지원 운영체제나 연결 방식은 이번 커밋 정보에 없으므로 별도 확인이 필요합니다.

## 릴리스: 0.1.11 준비

릴리스 영역에서는 0.1.11을 준비했습니다. 현재 주어진 기록은 릴리스 준비 커밋이므로, 배포를 마쳤거나 사용자가 이미 업데이트를 받을 수 있다고 안내하지는 않겠습니다. 같은 날 채팅 수정과 컴퓨터 기능 추가가 있었지만, 실제 배포본의 포함 범위도 릴리스 내역으로 확인해야 합니다.

이번 작업은 채팅 화면의 작은 정리와 컴퓨터 기능의 확장이 함께 진행됐다는 점에서 눈에 띕니다. 다만 기능이 추가됐다는 기록과 실제 지원 범위는 나눠 설명하는 편이 정확하겠습니다. 0.1.11을 소개할 때도 채팅의 변경 지점은 구체적으로 짚고, 새 조작 기능은 동작 조건을 확인한 뒤 안내할 필요가 있습니다.
