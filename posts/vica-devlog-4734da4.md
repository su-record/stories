# vica 개발일지: 채팅 화면부터 에이전트 실행·측정 기반까지

2026년 11월 5일의 vica 커밋 6개는 채팅 경험, 에이전트 실행, 모델 연결, 측정과 문서화로 묶을 수 있습니다. 입력창과 답변 주변의 화면 구성을 손보는 한편, 에이전트가 작업할 때 쓰는 도구와 지침, 권한 설정도 함께 다뤘습니다. 이번 기록은 커밋 메시지에서 확인할 수 있는 변경을 중심으로 정리했습니다. 실제 사용성이나 성능이 얼마나 달라졌는지는 별도의 검증이 필요한 부분입니다.

## 채팅: 답변 주변의 흐름과 설명 방식

채팅 화면은 입력창, 답변 아래의 ‘다음 할 일’, 표, 상태 막대를 시안에 맞춰 바꿨습니다. 메시지를 입력하는 곳부터 답변을 읽고 다음 행동을 고르는 곳까지, 대화 화면의 여러 요소를 함께 조정한 작업입니다. 표와 상태 막대도 변경 범위에 포함돼 있어 답변 본문뿐 아니라 정보를 보여주는 주변 구성까지 손봤습니다.

여기서 확인되는 것은 시안을 반영했다는 점입니다. 입력이 더 편해졌거나 다음 행동을 찾는 시간이 줄었다고 말하려면 사용 과정에서 확인해야 합니다. 화면을 바꾼 사실과 그 효과는 구분해서 보려고 합니다.

설명 방식에는 3D 설명 엔진을 추가했습니다. `explain` 장면을 통해 설명을 구성하는 기능입니다. 채팅 화면의 배치를 조정하는 작업과는 별개로, 설명을 표현하는 수단 자체를 넓힌 변화로 볼 수 있습니다. 다만 어떤 주제까지 지원하는지, 복잡한 장면을 얼마나 안정적으로 처리하는지는 이번 커밋 요약만으로 판단하기 어렵습니다.

## 에이전트: 도구 로딩부터 마무리 점검까지

에이전트 영역에서는 실행 과정의 여러 지점을 함께 보완했습니다. 도구 로딩에는 캐시를 유지하는 방식을 더했고, 에이전트에 전달할 지침으로 `AGENTS.md`를 주입하도록 했습니다. 도구를 준비하는 방식과 작업 지침을 전달하는 방식을 각각 다룬 셈입니다.

편집에는 관대 매칭을 추가했습니다. 편집 대상을 찾을 때 어느 정도의 차이까지 허용하는지는 세부 구현을 확인해야 하지만, 매칭 방식이 이번 변경의 한 축이라는 점은 분명합니다. 여기에 마무리 점검과 권한 모드도 더했습니다. 작업 중 편집뿐 아니라 종료 시점의 확인, 실행 권한을 다루는 설정까지 변경 범위가 이어집니다.

이 기능들이 추가됐다고 해서 편집 실패나 권한 관련 문제가 모두 해결됐다고 보기는 어렵습니다. 각 장치가 실제 작업에서 어떻게 작동하는지는 측정과 테스트로 확인할 몫입니다.

## 연결 설정: 서비스 표시와 우선순위 정리

연결 화면은 서비스를 3줄로 보여주는 구성과 우선순위를 중심으로 바꿨습니다. 연결 대상을 표시하는 형식뿐 아니라 우선순위도 화면 변경에 포함했습니다.

지원 항목에는 Vica 내장 모델, OpenGateway, `jev-omni`를 추가했습니다. 연결 선택지를 늘리는 작업과 이를 보여주는 화면 정리가 함께 들어갔다는 점이 이번 설정 변경의 특징입니다. 다만 각 항목의 기본값이나 우선순위가 실제 호출에 적용되는 규칙은 커밋 메시지에 나오지 않아 여기서는 단정하지 않겠습니다.

## 측정과 문서: 결과를 비교할 기반 추가

채팅 테스트에는 작업 성공 측정 묶음과 Claude·Codex 기준값을 더했습니다. 기능을 추가하는 것과 함께, 작업의 성공 여부를 측정하고 비교할 기준도 마련한 변화입니다. 기준값이 생겼다는 사실만으로 어느 쪽이 더 우수하다고 결론 내릴 수는 없습니다. 비교하려면 측정 조건과 실제 결과를 함께 봐야 합니다.

문서에는 측정, Every Joule, 하네스 비교, 연결 관련 지식을 기록했습니다. 테스트에 들어간 측정 자료와 관련 주제를 설명하는 문서가 같은 날 변경에 포함됐습니다.

이번 변경에서는 화면과 기능의 추가 범위가 넓었습니다. 지금 말할 수 있는 성과는 무엇을 바꿨고 어떤 검증 기반을 더했는지까지입니다. 사용성이 좋아졌는지, 작업 성공률이 달라졌는지는 새로 마련한 측정 자료와 실제 사용 결과를 바탕으로 살펴봐야겠습니다.
