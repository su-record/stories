# vica 개발일지: 모델 설정을 나누고 음성 입력을 정리했습니다

2026년 11월 26일의 vica 커밋 11개는 모델 설정과 음성 입력에 집중돼 있습니다. 설정에서는 **모델 등록과 모델 사용을 분리**하고, 로그인과 API 키로 접근하는 모델 목록을 다듬었습니다. 채팅 입력창에는 음성 입력과 통화를 따로 두고, 맥 앱의 마이크 권한도 함께 챙겼습니다.

## 모델을 등록하는 일과 사용하는 일을 나눴습니다

이번 설정 변경의 중심은 등록과 사용의 분리입니다. 모델을 연결해 두는 단계와 실제로 쓸 모델을 고르는 단계를 구분하도록 설정을 바꿨습니다. 같은 화면에서 다루더라도 두 작업의 목적은 다르기 때문에, 이 구분이 설정을 이해하는 기준이 되도록 했습니다.

이 구조에 맞춰 Seedance와 ElevenLabs도 연결했습니다. 영상 모델은 이미지에 섞이지 않도록 별도의 ‘동영상’ 분류로 옮겼습니다. 모델 연결을 늘리는 작업과 함께, 연결한 모델이 어느 영역에 속하는지도 정리한 셈입니다. 다만 이번 커밋 정보만으로 각 서비스에서 지원하는 세부 기능까지 설명하기는 어려워, 여기서는 연결과 분류 변경까지만 기록하겠습니다.

## 로그인과 API 키 목록의 겹침을 줄였습니다

모델 목록은 이름만 보고 정리하지 않고, 실제 호출 결과를 확인하는 방향으로 손봤습니다. API 키 모델을 모두 실제로 불러 보고, 로그인으로도 사용할 수 있는 모델은 로그인 중 API 키 목록에서 제외하도록 했습니다.

대화 모델도 ChatGPT 로그인으로 호출해 보는 대상에 포함했습니다. 로그인으로 사용할 수 있는 대화 모델을 키 목록에서 빼는 조정에 이어, 로그인 중 API 키 목록에는 대화 모델이 보이지 않도록 정리했습니다. 로그인과 키라는 접근 경로가 목록에 어떻게 반영되는지를 다듬은 작업입니다.

목록에 보여 주는 세대도 조정했습니다. 대화 모델은 최신 세대만 표시하고, 음성·이미지·임베딩·검수 모델도 최신 모델 위주로 보이게 했습니다. 여기서 구분할 점은 **목록에 노출하는 기준을 바꾼 것**이라는 점입니다. 이 변경을 곧바로 이전 모델의 지원 종료로 해석하지는 않으려 합니다.

## 판단 모델의 분류 오류도 바로잡았습니다

Gemini 판단 모델을 실시간 전용 모델로 잘못 보던 부분을 수정했습니다. 최신 모델 위주로 목록을 줄이는 작업과는 별개로, 모델의 용도를 잘못 분류한 문제를 고친 것입니다.

목록을 간추리는 기준과 용도를 구분하는 기준은 따로 확인해야 합니다. 이번에는 노출 범위를 정리하면서 이런 분류 오류도 함께 다뤘습니다. 특정 모델을 목록에서 어떻게 취급하는지 설명할 때, 세대와 용도를 혼동하지 않도록 기록에도 남겼습니다.

## 음성 입력과 통화의 진입점을 구분했습니다

채팅 입력창에서는 음성 입력과 통화를 따로 배치했습니다. 둘 다 마이크를 사용하는 기능이지만, 사용자가 시작하려는 작업은 다르므로 입력창에서도 각각 선택할 수 있게 했습니다.

맥 앱에는 마이크 사용 권한을 넣고 서명했습니다. 입력창에 음성 기능의 진입점을 마련하는 것과 앱이 마이크를 사용할 수 있도록 준비하는 일을 함께 진행했습니다. 다만 권한 추가만으로 모든 환경의 음성 동작을 확인했다고 말할 수는 없습니다. 이번 기록의 범위는 입력창 변경과 마이크 권한을 포함한 서명까지입니다.

## 설정 변경의 기준을 문서에도 남겼습니다

설정을 모델 등록과 모델 사용으로 나눈 시안을 문서화하고, 지식 문서에도 이 구분을 반영했습니다. 로그인 엔드포인트와 판단 모델에 관한 기록도 추가했습니다.

이번 작업은 모델 연결을 추가하는 데서 끝나지 않았습니다. 어떤 경로로 사용할 수 있는지 확인하고, 목록에 무엇을 보여 줄지 조정하며, 잘못된 분류를 고치는 데도 비중을 뒀습니다. 이후 설정을 다시 손볼 때는 이번에 남긴 문서를 기준으로 등록·사용 구조와 모델 목록의 처리 방식을 함께 살펴볼 수 있게 됐습니다.
