# vica 개발일지: 아이폰 연결부터 채팅 응답 정리까지

2026년 11월 13일의 vica 커밋 6개는 모바일 기기를 다루는 범위를 넓히고, 채팅에서 답을 기다리는 과정을 정리하는 데 초점을 맞췄습니다. 아이폰을 보고 조작하는 크레이트를 추가했고, 컴퓨터 유즈의 폰 대상과 오른쪽 패널에도 모바일 관련 기능을 넣었습니다. 채팅에서는 작업 중인 답의 표시 위치를 고정하고, 같은 영상 주소에 대해 저장된 분석을 다시 활용하도록 했습니다.

## 아이폰 연결을 컴퓨터 유즈로 이어가기

이번 모바일 작업의 출발점은 **아이폰에 아무것도 설치하지 않고 화면을 보고 조작하는 크레이트**입니다. 폰 쪽에 별도 앱을 설치하는 절차 없이 아이폰을 다룰 수 있도록 구현 범위를 넓혔습니다.

이 연결 기능은 컴퓨터 유즈에도 반영했습니다. 이제 컴퓨터 유즈의 폰 대상이 아이폰을 받습니다. 아이폰을 보고 조작하는 기능을 만드는 작업과, 컴퓨터 유즈에서 아이폰을 대상으로 받아들이는 작업이 각각 진행된 셈입니다. 두 변경을 함께 보면 기기 연결과 기능 사용 지점을 나누어 정리한 흐름이 드러납니다.

다만 이번 커밋 정보만으로 연결에 필요한 환경이나 지원하는 조작 범위까지 설명하기는 어렵습니다. “폰에 아무것도 깔지 않는다”는 특징은 분명하지만, 이를 별도 준비 없이 모든 환경에서 사용할 수 있다는 뜻으로 넓혀 말하지는 않겠습니다.

## 오른쪽 패널에 마련한 모바일 탭

화면 쪽에서는 오른쪽 패널에 모바일 탭을 추가했습니다. 모바일 관련 기능이 UI 안에서 자리 잡을 공간을 마련한 변경입니다. 아이폰 연결 기능을 추가한 것과 같은 날 진행됐지만, 연결을 구현하는 일과 사용자가 접하는 화면을 구성하는 일은 구분해서 볼 수 있습니다.

이번 기록에서 확인되는 UI 변화는 모바일 탭의 추가까지입니다. 탭 안에 어떤 제어 항목이 있는지, 연결 상태를 어떻게 보여주는지는 주어진 커밋 정보에 담겨 있지 않습니다. 그래서 사용 흐름이 모두 완성됐다고 표현하기보다는, 모바일을 다룰 화면 구성을 한 단계 진행했다고 정리하는 편이 정확하겠습니다.

아이폰 연결·모바일 탭·화면 그리기에 관한 기록도 함께 갱신했습니다. 기능 변경과 관련 기록을 같은 날 정리했다는 점은 남겨둘 만합니다. 다만 기록 갱신 자체를 별도의 화면 그리기 기능 추가로 세지는 않았습니다.

## 작업 중인 답의 표시 위치 지키기

채팅에서는 **작업 중인 답의 머리줄과 진행 줄이 제자리를 지키도록** 수정했습니다. 답변 내용을 늘리는 기능보다는, 답이 만들어지는 동안 보이는 화면을 다듬은 작업입니다.

응답이 아직 진행 중일 때는 머리줄과 진행 줄도 사용자가 현재 상태를 파악하는 단서가 됩니다. 이번 수정은 그 표시 위치가 유지되도록 하는 데 초점을 맞췄습니다. 어떤 화면 조건에서 문제가 생겼는지까지는 커밋 정보로 알 수 없으므로, 구체적인 재현 상황이나 원인을 덧붙이지는 않겠습니다.

## 같은 영상 주소에는 저장된 분석 활용하기

영상 관련 채팅에는 재사용 경로를 추가했습니다. 같은 영상 주소가 다시 들어오면 저장된 분석으로 답합니다. 이미 분석한 주소를 다시 요청했을 때, 이전 분석을 답변에 활용하도록 동작을 바꾼 것입니다.

여기서 재사용 기준으로 확인되는 것은 ‘같은 영상 주소’입니다. 주소가 달라도 같은 영상인지 판별하는지, 저장된 분석을 언제 갱신하는지는 이번 기록만으로 확인할 수 없습니다. 처리 시간이나 비용이 얼마나 달라졌는지도 수치로 말할 근거는 없습니다. 이번 개발일지에서는 저장된 분석을 다시 쓰는 기능이 들어왔다는 점까지만 다루겠습니다.

이번 변경은 아이폰 지원을 연결 계층과 컴퓨터 유즈로 확장하면서 모바일 UI를 마련하고, 채팅의 진행 표시와 영상 분석 재사용을 함께 손본 작업이었습니다. 새로 다룰 수 있는 대상을 늘린 부분과 기존 응답 흐름을 정리한 부분을 나누어 보면, 이번 여섯 커밋의 역할이 조금 더 또렷해집니다.
