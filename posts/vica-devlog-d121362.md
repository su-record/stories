# vica 개발일지: 0.2.4 설치본 점검과 데스크톱 표시 수정

2026년 11월 25일의 vica 작업은 설치된 앱에서 확인한 결과를 남기고, 데스크톱 화면에 드러나는 표현을 다듬는 데 집중됐습니다. 최근 커밋 세 개를 영역별로 묶으면 **설치본 테스트와 앱 안 업데이트 검증**, **모델 선택 단추와 다음 요청 제안 수정**으로 정리할 수 있습니다. 기능을 더했다는 이야기보다는, 실제로 확인한 범위와 고친 부분을 기록하는 개발일지에 가깝습니다.

## 설치본 테스트와 업데이트 경로 기록

먼저 **0.2.4 설치본으로 실제 앱을 테스트한 결과와 수정한 내용을 지식 문서에 남겼습니다.** 설치된 앱을 대상으로 확인했다는 점이 이번 기록의 기준입니다. 다만 커밋 요약에는 세부 테스트 항목이나 전체 결과가 담겨 있지 않습니다. 따라서 모든 기능을 검증했다거나, 발견한 문제를 전부 해결했다고 넓혀 말하지는 않겠습니다.

테스트 결과와 고친 내용을 함께 기록하면 이후에 같은 버전을 살펴볼 때 확인 결과와 수정 사항을 나란히 참고할 수 있습니다. 이번 문서 작업도 그 용도로 볼 수 있습니다. 구체적인 재현 조건이나 항목별 결과가 필요할 때는 커밋 제목만으로 판단하지 않고 해당 문서 내용을 확인해야 합니다.

업데이트 쪽에서는 조금 더 명확한 확인 지점이 있습니다. **윈도 환경에서 앱이 앱 안 업데이트를 통해 0.1.10에서 0.2.4로 실제로 올라간 사실**을 별도로 기록했습니다. 0.2.4 설치본을 테스트한 기록과는 확인 대상이 다릅니다. 하나는 설치된 버전의 동작을 살펴본 것이고, 다른 하나는 이전 버전에서 새 버전으로 이동하는 경로를 확인한 것입니다.

이번에 확인된 경로는 윈도의 0.1.10 → 0.2.4입니다. 다른 운영체제나 다른 출발 버전에서도 같은 결과가 나온다고 단정할 근거는 없습니다. 범위를 좁혀 적더라도, 어떤 환경에서 어떤 버전 사이의 앱 안 업데이트가 실제로 됐는지 남기는 편이 다음 점검에 도움이 됩니다.

## 모델 선택 단추의 표시 정리

데스크톱에서는 자동 모델 단추에 **“자동”만 표시하도록 수정했습니다.** 단추에서 사용자가 읽게 되는 문구를 분명하게 정리한 변경입니다.

여기서 표시 수정과 모델 선택 동작은 구분해 두려고 합니다. 제공된 커밋 내용으로 확인할 수 있는 것은 단추에 보이는 표현이 바뀌었다는 사실입니다. 자동으로 모델을 고르는 기준이나 요청 처리 방식까지 달라졌다는 내용은 없습니다. 이번 개발일지에서도 그 범위를 넘어 성능이나 선택 정확도가 개선됐다고 설명하지 않겠습니다.

## 다음 요청 제안에 섞이는 내용 수정

다음 요청 제안에는 **깨진 글자와 화면 JSON이 들어가지 않도록 수정했습니다.** 사용자가 다음에 요청할 내용을 읽는 자리에, 읽기 어려운 문자나 화면을 표현하는 JSON이 섞이는 문제를 다룬 작업입니다.

제안 문구는 사용자가 읽고 이어서 요청할 수 있어야 합니다. 여기에 깨진 글자나 화면 JSON이 포함되면 제안의 내용을 파악하기 어려워질 수 있습니다. 이번 수정은 그런 내용이 제안에 들어가지 않게 하는 데 초점이 있습니다. 다만 어떤 처리 단계에서 이를 막았는지, 어떤 입력 사례로 검증했는지는 커밋 요약에 없어 구현 방식까지 추정하지는 않았습니다.

이번 기록에 남길 핵심은 확인 범위가 서로 다르다는 점입니다. 설치본 테스트 문서에는 0.2.4의 실제 앱 테스트 결과와 수정 사항을, 업데이트 문서에는 윈도의 특정 버전 간 이동 성공을 남겼습니다. 데스크톱 코드에서는 단추 표시와 다음 요청 제안에 포함되는 내용을 고쳤습니다. 이후 점검에서도 이 구분을 유지하면, 이미 확인한 사실과 추가로 살펴봐야 할 부분을 혼동하지 않고 이어갈 수 있겠습니다.
