# vica 개발일지: 지식 도구를 앱 안으로 옮기고, 유튜브 분석 도구를 더했습니다

2026년 11월 12일, vica에서 지식을 찾고 문서를 읽는 경로를 정리하고 유튜브 영상 분석 도구를 추가했습니다. 최근 커밋 네 개를 영역별로 묶으면, 지식 도구의 앱 내부 처리와 영상 분석 기능 추가, 그리고 관련 기록 갱신으로 나눌 수 있습니다. 이번 작업에서 눈여겨볼 부분은 도구의 종류뿐 아니라 도구가 어디에서 실행되는지도 달라졌다는 점입니다.

## 지식 찾기와 읽기를 앱 안에서 처리합니다

채팅에서 지식을 찾고 읽는 작업은 이제 별도의 vibe 프로그램 없이 앱 안에서 처리합니다. 사용자가 요청하는 일은 여전히 지식 검색과 읽기지만, 이를 수행하기 위해 거치는 실행 경로를 바꿨습니다.

이 변화는 기능 추가보다는 내부 구조 정리에 가깝습니다. 앱이 지식 도구를 사용하면서 별도 프로그램에 맡기던 부분을 앱 내부로 가져왔습니다. 덕분에 이번 변경을 살펴볼 때도 검색 결과의 변화와 실행 구조의 변화를 구분해야 합니다. 커밋에서 확인되는 것은 처리 위치가 달라졌다는 사실이며, 검색 품질이나 응답 속도가 개선됐다고까지 말할 근거는 아직 없습니다.

문서 읽기에서는 Python 경로도 없앴습니다. 지식 찾기·읽기의 앱 내부 처리와 함께 보면, 관련 작업에서 외부 실행 경로를 줄이는 방향으로 구조를 정리한 셈입니다. 다만 제거 범위는 문서 읽기입니다. 이 변경만으로 vica 전체에서 Python을 사용하지 않게 됐다고 해석하지는 않으려 합니다.

두 변경을 같은 영역으로 묶은 이유도 여기에 있습니다. 하나는 지식 도구가 vibe 프로그램을 거치지 않도록 했고, 다른 하나는 문서 읽기에 남아 있던 Python 경로를 제거했습니다. 지식에 접근하는 흐름을 앱 안으로 모으는 작업으로 볼 수 있습니다.

## 구글 키가 있을 때 유튜브 영상을 분석합니다

채팅에는 유튜브 영상을 보고 분석하는 도구를 추가했습니다. 문서와 지식을 다루던 도구 구성에 영상 분석이라는 용도가 더해졌습니다.

사용 조건은 분명합니다. **구글 키가 있을 때 사용할 수 있는 도구**입니다. 따라서 이번 추가를 모든 환경에서 바로 쓸 수 있는 기능으로 소개하기보다는, 키가 준비된 환경에서 활용할 수 있는 도구로 설명하는 편이 정확합니다.

현재 커밋 정보만으로는 지원하는 영상의 범위나 분석 결과의 형식, 처리 시간까지 확인할 수 없습니다. 이번 개발일지에서는 유튜브 영상을 분석하는 도구가 생겼다는 점과 구글 키가 필요하다는 조건까지 기록해 둡니다. 실제 활용 범위를 설명하려면 이 부분은 별도로 확인해야 합니다.

## Rust 이전 목록과 도구 기록을 갱신했습니다

구현 변경에 맞춰 Rust 이전 목록, 영상 도구 기록, 지식 도구 기록도 갱신했습니다. 실행 경로를 바꾸고 도구를 추가한 만큼, 관련 기록도 함께 손본 작업입니다.

여기서 Rust 이전 목록을 갱신했다는 사실과 Rust 이전을 완료했다는 주장은 구분해야 합니다. 이번 커밋 정보가 알려 주는 범위는 목록의 갱신까지입니다. 이전이 어디까지 진행됐는지, 어떤 항목이 남았는지는 이 정보만으로 단정하지 않겠습니다.

이번 작업은 지식 도구의 실행 경로를 정리하는 일과 영상 분석 기능을 넓히는 일이 함께 진행됐습니다. 지식 찾기·읽기는 앱 내부로 옮겼고, 문서 읽기에서는 Python 경로를 제거했습니다. 유튜브 분석은 구글 키가 있다는 조건 아래 추가했습니다. 이후 변경을 살펴볼 때도 내부 처리 경로와 도구 사용 조건을 나눠 확인하면, 무엇이 달라졌는지 더 정확히 짚을 수 있겠습니다.
