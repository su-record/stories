# vibe 개발일지 #62 - 655MB 용량 폭탄을 해결하고 npm 12 환경에 대응하기 (11개 커밋)

**작업 기간**: 2026-08-13

안녕하세요, Su입니다! AI 코딩 하네스 도구인 `vibe`(@su-record/vibe)를 개발하면서 배운 기술적 도전과 삽질의 기록을 공유합니다.

"Agent = Model + Harness"라는 철학 아래, 모델이 아무리 똑똑해도 하네스가 든든하게 받쳐주지 않으면 생산성이 떨어집니다. 오늘 일지에서는 플러그인 배포 과정에서 터진 어처구니없는 용량 문제와 npm 12 업데이트 환경에 대응한 경험을 정리해 봅니다.

---

## 📝 이번 기간 작업 내용

이번 11개의 커밋은 크게 **'플러그인 시스템 CLI 최적화'**와 **'npm 12 대응 및 네이티브 바인딩 자동 복구'**라는 두 가지 축으로 진행되었습니다.

### 1. 플러그인 시스템 CLI 구현 및 빌드 트리 최적화
- **npm 사용자용 CLI 제공**: npm 설치 사용자가 쉽게 플러그인을 확장할 수 있도록 `vibe plugin` 명령어를 구현했습니다. (PR #57)
- **배포 트리를 조립하는 방식으로 설치 구조 변경**: 플러그인 설치 시 프로젝트 루트를 잘못 참조하여 전체 용량이 655MB까지 불어나는 치명적인 문제를 수정했습니다. (PR #56)

### 2. npm 12 `allowScripts` 대응 및 네이티브 바인딩 자기복구
- **네이티브 바인딩 자동 복구(Self-Recovery) 구현**: npm 12의 더욱 엄격해진 `allowScripts` 정책으로 인해 `postinstall` 등이 스킵되며 네이티브 바인딩이 누락되는 현상을 감지하고, 실행 시점에 스스로 복구하도록 개선했습니다. (PR #58)
- **사용자 경험 안내 지속화**: 네이티브 바인딩 관련 힌트 메시지가 일회성으로 사라지지 않고 필요한 순간에 지속 안내되도록 보완했습니다. (PR #59)
- **문서 및 승인 효과 범위 정정**: `allowScripts` 승인 시 스코프와 효과 범위를 명확히 알릴 수 있도록 업그레이드 가이드 문서를 수정했습니다. (PR #60)

## 💡 작업 하이라이트

### 1. 655MB 용량 폭탄 참사와 빌드 트리 조립
개발을 진행하다 보면 가끔 아차 싶은 순간이 있습니다. npm 설치 사용자분들을 위해 `vibe plugin` CLI 명령을 만들고 신나게 테스트를 해보는데, 이상하게 플러그인 설치만 하면 디스크 용량이 훅 줄어드는 느낌이 들었습니다.

확인해 보니 플러그인 배포용 파일만 추출해서 복사해야 하는데, 복사 대상 경로가 **프로젝트 루트 디렉토리**를 가리키고 있었습니다. 결과적으로 `.git`, `node_modules`, 각종 빌드 아티팩트가 모두 포함되어 **플러그인 하나 설치하는 데 655MB가 복사**되고 있었던 것이죠.

```
[Before]
vibe plugin install
  └─ 루트 전체 복사 (/vibe/*) ➔ 655MB (node_modules, cache 포함... 😱)

[After]
vibe plugin install
  └─ 정교하게 조립된 빌드 트리만 복사 (/dist/plugin/*) ➔ 약 2.1MB ✨
```

배포에 필요한 최소한의 아티팩트만 모아 '빌드 트리'를 조립(Assemble)한 뒤 설치하도록 구조를 변경했습니다. 약 99.6%의 용량을 다이어트하며 깔끔하게 최적화했습니다.

### 2. npm 12 `allowScripts` 정책과 하네스의 자기복구(Self-Recovery)
최근 npm 12로 넘어가면서 보안 정책으로 인해 `allowScripts` 설정이 없는 패키지의 라이프사이클 스크립트 실행이 제한되기 시작했습니다. 이로 인해 빠른 도구 실행을 위해 사용 중인 네이티브 바인딩 모듈이 정상 설치되지 않고 빌드가 누락되는 이슈가 발생했습니다.

하네스 도구의 핵심은 **"개발자가 신경 쓸 필요 없이 자동으로 품질과 환경을 보장하는 것"**입니다.
따라서 CLI 실행 시 네이티브 바인딩이 유실된 상태를 스스로 감지(Detect)하면, 툴이 튕기는 대신 내부에서 바인딩을 재구성하는 **자기복구(Self-Recovery)** 로직을 태우도록 만들었습니다.
