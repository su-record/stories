# vibe 개발일지 #61 - Codex 플러그인 패키징과 PostCompact 훅 도입 (10개 커밋)

**작업 기간**: 2026-08-12 ~ 2026-08-13

안녕하세요, vibe 프로젝트를 개발하고 있는 10년 차 프론트엔드 개발자 Su입니다.

"Agent = Model + Harness"라는 철학 아래, AI가 작성하는 코드의 최소 품질을 보장하기 위한 하네스 도구 `@su-record/vibe`를 열심히 다듬고 있습니다. 이번 이틀 동안은 Codex 생태계로의 확장과 대화가 길어졌을 때 AI가 맥락을 잃는 문제를 해결하는 작업에 집중했습니다.

## 📝 이번 기간 작업 내용

이번 10개의 커밋은 크게 **플러그인 생태계 확장**, **컨텍스트 보존 및 스킬 리팩토링**, **문서 및 부채 정산**의 3가지 영역으로 나누어 진행했습니다.

### 1. Codex / ChatGPT 플러그인 패키징 (`feat(plugin)`)
* **Codex/ChatGPT 플러그인 패키징 (단계 1)**: CLI 환경을 넘어 Codex/ChatGPT 내에서 vibe의 하네스 기능을 직접 활용할 수 있도록 플러그인 규격으로 패키징을 시작했습니다.
* **로컬 마켓플레이스 항목 및 설치 문서 추가**: 로컬 환경에서 플러그인을 손쉽게 테스트하고 설치할 수 있도록 마켓플레이스 매니페스트와 가이드를 작성했습니다.

### 2. 컨텍스트 보존 및 스킬 시스템 개선 (`feat(codex)`, `refactor(skills)`)
* **PostCompact 훅 도입**: Codex 대화 압축(Compaction)이 발생한 직후 핵심 지침(ANCHOR)을 다시 고정하고 낡은 교리를 정정하는 훅을 구현했습니다.
* **SSOT 포인터 기반 스킬 정리**: 정보 손실이 발생하는 스킬 요약본 방식을 버리고, 단일 진실 공통원(SSOT)을 직접 가리키는 포인터 방식으로 리팩토링했습니다. ("Repeat yourself → Simple" 원칙 적용)

### 3. 문서 최신화 및 밀린 작업 정산 (`docs`)
* **사실 관계 정정 및 Harness 분할**: 기존 문서 중 구현과 다르게 서술된 부분을 수정하고, 보류해 두었던 아카이브 주석 정벌, 명령어 표 완성, harness 모듈 분할을 깔끔하게 마무리했습니다.

## 💡 작업 하이라이트

### 1. 대화가 길어져도 흔들리지 않는 AI: `PostCompact` 훅

AI 모델과 긴 티키타카를 주고받다 보면 컨텍스트 창 용량이 차서 대화 내용을 요약/압축(Compaction)하는 순간이 올 때가 있습니다. 문제는 이 압축 과정에서 vibe가 정해둔 핵심 품질 규칙(ANCHOR)이 날아가거나 요약되어, 압축 직후부터 AI가 엉뚱한 코드를 짜기 시작한다는 점이었습니다.

이를 해결하기 위해 **`PostCompact` 훅**을 도입했습니다.

```
[기존 Workflow]
긴 대화 진행 ➔ 컨텍스트 압축(Compaction) ➔ ANCHOR 유실 ➔ AI 품질 저하 😭

[개선된 Workflow (PostCompact Hook)]
긴 대화 진행 ➔ 컨텍스트 압축(Compaction) ➔ PostCompact Trigger ➔ ANCHOR 즉시 재고정 ➔ 일관된 품질 유지 🚀
```

압축 이벤트가 실행되는 즉시 `PostCompact` 훅이 작동하여 가장 최신의 ANCHOR를 컨텍스트 상단에 다시 고정해 줍니다. 덕분에 AI가 오랜 시간 작업을 하더라도 처음 약속했던 코드 품질과 교리를 끝까지 준수할 수 있게 되었습니다.

### 2. 스킬 시스템의 SSOT(Single Source of Truth) 전환

기존에는 AI에게 전달할 스킬 정보를 텍스트 요약본 형태로 들고 있었습니다. 하지만 관리가 진행될수록 원본 문서와 요약본 사이의 동기화가 깨지고, 요약 과정에서 중요한 맥락이 손실되는 문제가 생겼습니다.

이번 작업에서는 "중복되더라도 단순하게 유지하라(Repeat yourself → Simple)"는 원칙을 바탕으로, 손실이 발생하는 요약본을 완전히 제거하고 SSOT 원본을 직접 지시하는 포인터 구조로 리팩토링했습니다. 결과적으로 스킬 관리의 복잡성이 대폭 줄어들었고 AI에게 전달되는 지침의 명확성도 높아졌습니다.
