# vica 개발일지: Chat 지식 저장 경로와 데스크톱 사용 흐름 정리

2026년 10월 30일의 최근 커밋 3개에서는 vica 데스크톱의 지식 저장 방식과 설정 동작을 손봤습니다. Chat 요청을 지식으로 남길 때 vibe 없이도 선택한 폴더에 저장할 수 있게 했고, 에이전트 CLI 설치·업데이트는 백그라운드에서 처리하도록 바꿨습니다. git 설정에서 가져온 기본 커밋 작성자가 이후 설정 변경을 따라가지 못하던 문제도 수정했습니다. 이번 작업을 저장 경로, 데스크톱 사용 흐름, git 연동으로 나눠 정리해 보겠습니다.

## 지식 저장: vibe 없이도 선택한 폴더로

Chat 요청을 지식으로 저장하는 데 vibe가 꼭 필요하지 않도록 바꿨습니다. 이제는 사용자가 고른 폴더에 지식을 저장할 수 있습니다. 저장 기능을 쓰기 위해 vibe를 함께 사용하는 구성을 전제하지 않아도 된다는 점이 이번 변경의 핵심입니다.

vibe를 사용하는 경우에도 저장 위치를 조정할 수 있도록 했습니다. 설정에서 vibe 위키 폴더를 바꿀 수 있게 한 것입니다. vibe 없이 저장할 폴더를 고르는 기능과, vibe 위키 폴더를 설정에서 변경하는 기능은 모두 저장 경로를 다루지만 적용 대상은 다릅니다. 이번에는 두 경우를 함께 다뤄, 각 사용 방식에 맞춰 경로를 선택할 수 있게 했습니다.

다만 이번 커밋 정보만으로는 기존 지식 파일을 새 폴더로 옮기는지, 경로 변경 뒤 파일을 어떻게 관리하는지까지 설명하기는 어렵습니다. 여기서 확인할 수 있는 변화는 Chat 요청의 폴더 저장 지원과 vibe 위키 경로의 설정 기능입니다.

## 데스크톱: CLI 관리와 탭·설정 화면 정리

에이전트 CLI는 뒤에서 설치하고 업데이트하도록 바꿨습니다. 데스크톱 앱에서 사용하는 CLI의 준비와 갱신을 백그라운드 작업으로 처리하는 방향입니다. 사용자가 Chat 지식의 저장 위치를 고르는 작업과는 별개로, 앱이 사용하는 도구의 설치·업데이트 흐름을 정리한 변경입니다.

백그라운드 처리라고 해서 설치가 즉시 끝나거나 모든 상황에서 작업이 끊기지 않는다고 말할 수는 없습니다. 설치 진행 표시, 실패했을 때의 안내, 재시도 방식은 주어진 커밋 정보에 드러나지 않습니다. 따라서 이번 일지에서는 설치 속도나 안정성의 개선까지 단정하지 않고, 처리 방식이 바뀌었다는 데 초점을 맞추겠습니다.

같은 데스크톱 영역에서는 탭 닫기와 탭 순서, 설정 화면도 다듬었습니다. 탭을 정리하는 동작과 설정을 확인하는 화면을 손본 작업입니다. 다만 구체적인 조작 방식이나 화면 배치까지는 확인할 수 없어, 새로운 단축키나 드래그 동작이 추가됐다고 소개하지는 않겠습니다.

## git 연동: 기본 작성자도 설정 변경을 따라가도록

git 설정으로 채운 기본 커밋 작성자가 git 설정 변경을 따라가도록 수정했습니다. git에서 가져온 값을 사용하면서도 원본 설정이 바뀐 뒤에는 이전 작성자 정보가 남는 문제를 다룬 것입니다.

이 부분에서는 ‘기본값을 어디서 가져오는가’뿐 아니라 ‘가져온 뒤 언제 갱신하는가’도 중요합니다. git 설정을 기준으로 작성자를 채운다면, 그 설정의 변경도 반영되어야 기본값의 출처와 실제 동작이 맞습니다. 이번 수정은 그 관계를 바로잡는 작업입니다. 다만 사용자가 직접 입력한 작성자 정보까지 덮어쓰는지는 제공된 내용으로 확인할 수 없으므로 구분해서 봐야 합니다.

이번 세 커밋은 저장 위치를 직접 고를 수 있는 범위를 넓히고, CLI 관리와 데스크톱 조작을 정리하며, git에서 가져온 기본값의 갱신 문제를 수정했습니다. 특히 저장 경로처럼 사용자가 결정하는 값과 커밋 작성자처럼 외부 설정에서 가져오는 값을 각각 어떻게 다룰지 손본 점이 이번 작업의 중심이었습니다.
