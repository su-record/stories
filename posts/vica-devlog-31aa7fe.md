# vica 개발일지: Windows 0.2.4 공개와 플랫폼별 배포 안내 정리

2026년 11월 24일에는 vica 0.2.4 배포를 준비하면서, Windows가 먼저 공개된 상황에 맞춰 배포 처리와 문서를 손봤습니다. 이번 작업은 버전 및 배포 노트 정리, macOS 합류 시 최신 배포 표시 수정, 내려받기 안내와 지식 문서 갱신으로 묶을 수 있습니다. 두 플랫폼의 공개 버전이 잠시 다른 상태를 안내에 반영하는 데 초점을 맞췄습니다.

## 버전과 배포 노트: 0.2.4에 담긴 변경 정리

프로젝트 버전을 0.2.4로 올리고, 배포 노트에 Windows 관련 내용과 이날 수정한 컴퓨터 조작 내용을 넣었습니다. 버전 번호를 갱신하는 작업에 더해, 이번 배포에서 무엇을 확인해야 하는지도 함께 정리한 셈입니다.

다만 제공된 커밋 정보만으로는 컴퓨터 조작의 어떤 동작을 어떻게 고쳤는지까지 설명하기 어렵습니다. 따라서 이 일지에서는 해당 수정이 배포 노트에 반영됐다는 범위까지만 말씀드리겠습니다. 구체적인 증상이나 개선 효과를 덧붙이면 실제 변경보다 설명이 앞설 수 있기 때문입니다.

이번 공개 상태에서 구분해야 할 점은 **프로젝트의 버전과 플랫폼별로 내려받을 수 있는 버전이 같지 않다**는 것입니다. Windows는 0.2.4를 먼저 공개했고, macOS 내려받기 안내는 0.2.3을 유지했습니다. 이 차이가 다음 두 영역의 수정으로 이어졌습니다.

## 배포 처리: 나중에 합류하는 macOS도 고려

배포 로직에서는 Windows판이 먼저 나온 배포에 macOS판이 합류할 때, 그 배포를 최신으로 표시하도록 수정했습니다. 플랫폼별 결과물이 같은 시점에 나오지 않는 경우를 다룬 변경입니다.

여기서 수정 조건은 단순히 “macOS를 배포할 때”가 아닙니다. **Windows판이 먼저 공개된 배포에 macOS판이 뒤이어 합류하는 경우**입니다. 먼저 공개된 플랫폼만 기준으로 보면 놓칠 수 있는 후속 배포 단계를 처리하도록 손본 것입니다.

이 커밋은 macOS 0.2.4가 이미 공개됐다는 뜻으로 읽어서는 안 됩니다. 이번에 확인되는 내용은 합류 시 최신 배포를 표시하는 처리의 수정이며, 같은 날 README에 반영한 macOS 내려받기 버전은 여전히 0.2.3입니다. 배포 동작의 변경과 현재 공개 상태를 구분해서 기록했습니다.

## 문서: 내려받기 안내와 배포 경위 맞추기

README의 내려받기 안내는 macOS 0.2.3, Windows 0.2.4로 맞췄습니다. 사용자가 자신의 운영체제에 맞는 버전을 찾는 곳인 만큼, 두 플랫폼을 하나의 버전으로 묶어 안내하지 않았습니다. Windows의 새 버전 공개가 곧 macOS의 같은 버전 공개를 의미하지 않도록 한 정리입니다.

지식 문서에는 Windows 0.2.4를 먼저 공개한 상황과 중계 배포를 기록했습니다. README가 현재 내려받을 버전을 안내한다면, 지식 문서는 배포 경위를 남기는 역할을 합니다. 다만 중계 배포의 구체적인 구성이나 절차는 제공된 커밋 정보에 없으므로 여기서 별도로 설명하지는 않겠습니다.

이번 네 커밋은 배포 상태, 후속 플랫폼 합류 처리, 사용자 안내를 서로 맞추는 작업으로 이어졌습니다. 현재 안내는 Windows 0.2.4와 macOS 0.2.3으로 구분했고, 이후 macOS가 합류할 때의 최신 배포 표시도 수정했습니다. 플랫폼마다 공개 시점이 다른 구간을 코드와 문서 양쪽에서 다룬 하루였습니다.
