# Vica 개발일지: Windows 0.1.4 배포와 Bash 터미널·업데이터

이번 `vica`의 최근 커밋 3개는 Windows 버전 배포와 배포 기록에 집중돼 있습니다. 2026년 11월 7일에는 Windows 0.1.3 배포를 문서에 남겼고, 다음 날에는 Bash 터미널과 업데이터를 포함한 0.1.4를 배포했습니다. 이어서 검증된 0.1.4 배포 사실도 문서에 기록했습니다.

이번 일지는 기능 변경과 배포 문서화로 나누어 정리했습니다. 다만 확인할 수 있는 자료가 커밋 메시지뿐이라, 세부 구현이나 테스트 결과까지 설명하기는 어렵습니다. 기능이 포함됐다는 사실과 실제 사용 방식은 구분해서 적겠습니다.

## Windows 기능: Bash 터미널과 업데이터

Windows 0.1.4에서 이름이 명시된 기능은 **Bash 터미널과 업데이터**입니다. 두 기능을 포함한 버전을 배포했다는 점이 이번 변경의 중심입니다.

Bash 터미널은 터미널 사용 영역의 변화입니다. 다만 커밋 메시지에는 어떤 Bash 실행 환경을 사용하는지, 별도 설치가 필요한지, 기존 터미널과 어떻게 연결되는지가 나와 있지 않습니다. 따라서 WSL이나 Git Bash를 지원한다고 특정하거나, 설치 직후 바로 사용할 수 있다고 안내할 근거는 없습니다. 지금 소개할 수 있는 범위는 Windows 0.1.4에 Bash 터미널이 포함됐다는 데까지입니다.

업데이터도 같은 기준으로 살펴봤습니다. 업데이트를 다루는 기능이 이번 배포에 포함됐지만, 새 버전을 자동으로 확인하는지, 다운로드와 설치 중 어디까지 처리하는지는 메시지만으로 알 수 없습니다. ‘업데이터 포함’을 ‘사용자 조작 없이 자동 업데이트 완료’로 받아들이지 않도록 구분할 필요가 있습니다.

기능 이름만으로도 이번 릴리스가 다루는 영역은 알 수 있습니다. 다만 실제 사용 안내를 작성하려면 터미널 실행 조건과 업데이트 절차를 추가로 확인해야겠습니다. 아직 확인하지 못한 동작을 편의성이나 안정성 개선으로 묶어 설명하지는 않겠습니다.

## 배포 기록: 0.1.3에서 0.1.4까지

문서 변경은 두 버전의 배포 사실을 남기는 데 집중됐습니다. 11월 7일의 기록은 Windows 0.1.3 배포를, 11월 8일의 기록은 **검증된 Windows 0.1.4 배포**를 다룹니다. 최근 이틀의 기록에서 이전 버전의 배포 문서화와 다음 버전의 기능 배포, 후속 문서화를 함께 확인할 수 있습니다.

여기서 눈여겨볼 표현은 0.1.4 배포 기록에 붙은 ‘검증된’이라는 말입니다. 배포 사실을 검증해 기록했다는 점은 드러나지만, 검증 항목이나 방법까지 제공되지는 않았습니다. 설치, 실행, Bash 터미널, 업데이터를 모두 시험했다고 확대해서 해석할 수는 없습니다.

0.1.3 역시 배포 기록이 있다는 사실만 확인됩니다. 이번 자료에는 해당 버전의 기능이나 수정 내역이 없으므로, 0.1.4와의 상세 비교는 하지 않았습니다. 날짜가 하루 차이라는 이유로 긴급 수정이나 배포 문제를 추정할 근거도 없습니다.

## 이번 기록에서 남길 내용

이번 작업은 Windows 0.1.4에 Bash 터미널과 업데이터를 담아 배포하고, 그 배포 사실을 검증된 기록으로 문서에 남긴 흐름으로 정리할 수 있습니다. 앞선 0.1.3 배포 기록도 함께 남아 버전별 배포 이력을 살펴볼 단서가 생겼습니다.

사용 방법까지 담은 개발일지로 이어가려면 Bash 환경의 요구 조건, 업데이터의 동작 범위, 배포 검증 항목이 더 필요합니다. 이번에는 확인된 배포와 기능 범위까지만 기록해 두겠습니다.
