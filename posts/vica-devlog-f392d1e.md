# vica 개발일지: 터미널 선택부터 에이전트에 맥락 전달하기까지

2026년 10월 30일의 최근 커밋 6개에서는 터미널과 에이전트를 여는 방식, 작업을 이어 가는 기능, 파일과 대화 화면을 함께 손봤습니다. 이번 변경을 묶어 보면 시작할 도구를 고르고, 필요한 내용을 전달하고, 하던 작업으로 돌아오는 흐름에 초점이 맞춰져 있습니다. 커밋에 담긴 변경을 기능별로 정리해 보겠습니다.

## 터미널과 에이전트, 시작할 때부터 구분하기

새 터미널 메뉴는 **OS 터미널·bash·에이전트**로 나눴습니다. 터미널을 연다는 같은 동작 안에서도 어떤 환경을 시작하려는지 구분할 수 있도록 한 변경입니다. 에이전트별 시작 명령을 설정하는 기능도 추가했습니다. 실행할 대상을 고르는 메뉴와 실제로 실행할 명령을 지정하는 설정이 각각 생긴 셈입니다.

에이전트 설정에는 별칭 등록 버튼과 권한 모드 선택을 넣었습니다. 권한 모드는 기본·자동 승인·욜로로 구분됩니다. 에이전트를 어떻게 시작할지뿐 아니라 어떤 권한 모드로 사용할지도 설정 화면에서 다루게 됐습니다.

다만 모드 이름만으로 세부 승인 범위까지 설명할 수는 없습니다. 이번 커밋 정보에서 확인되는 것은 세 가지 선택지가 추가됐다는 점입니다. 각 모드가 어떤 동작을 승인하는지, 에이전트마다 차이가 있는지는 별도로 확인해야 합니다.

## vica 칸 안으로 들어온 bash와 에이전트 연동

holder 영역에서는 bash 칸 통합과 에이전트 이어 하기를 작업했습니다. 데스크톱의 시작 메뉴를 나누는 변경과 함께 보면, 실행 대상을 선택하는 입구와 칸 안에서 작업을 이어 가는 기능을 함께 다룬 업데이트입니다.

에이전트 훅 연동도 추가했습니다. **Codex·Antigravity·Grok에 훅을 붙였고, Muse Code는 훅·이어 하기·욜로까지 vica 칸에 연결했습니다.** 에이전트마다 커밋에 명시된 연동 범위가 다르므로, 모두 같은 기능을 지원한다고 묶어 말하지는 않겠습니다.

이번 holder 변경에서 눈여겨볼 부분은 ‘이어 하기’입니다. 새로 실행하는 기능과 별개로, 진행하던 에이전트 작업으로 돌아오는 기능을 추가했습니다. 다만 이어 하기가 복원하는 상태의 범위나 훅의 구체적인 이벤트 목록은 커밋 메시지만으로 확인하기 어렵습니다.

## 파일을 고치고, 필요한 부분을 대화로 넘기기

파일 탭에는 바로 편집하는 기능을 추가했습니다. 내용을 확인하던 탭에서 수정까지 할 수 있게 된 변화입니다. 파일을 보는 화면의 역할이 편집으로 넓어졌습니다.

여기에 **선택한 줄과 터미널 출력을 에이전트 또는 Vica에 전달하는 기능**을 붙였습니다. 파일에서 짚고 싶은 부분이나 터미널에 나온 결과를 대화의 재료로 넘길 수 있습니다. 편집 기능과 함께 보면, 파일을 확인하고 수정하는 흐름에 에이전트에게 내용을 전달하는 동작이 연결된 것입니다.

전달 대상을 에이전트와 Vica로 구분한 점도 포함됩니다. 다만 선택한 내용 외에 어떤 정보가 함께 전달되는지는 이번 자료에 없으므로, 자동으로 전체 맥락을 넘겨준다고 설명하지는 않겠습니다.

## 버튼과 Chat 목록 정리

화면에서는 버튼을 아이콘과 툴팁으로 바꾸고, Chat 인사를 다듬었습니다. 버튼의 표시 방식과 설명을 손보는 작업입니다. 실제로 얼마나 찾기 쉬워졌는지는 사용하면서 확인할 부분입니다.

대화 목록에서는 고정·보관·삭제를 다듬었습니다. 에이전트 실행과 파일 작업에 기능을 더하는 한편, 쌓인 대화를 관리하는 화면도 함께 정리했습니다.

이번 여섯 커밋은 시작 메뉴, 작업 칸, 파일 탭, Chat 목록에 걸쳐 있습니다. 기능 추가 범위는 넓지만, 커밋 정보만으로 사용성이나 안정성까지 평가하기는 어렵습니다. 이번 개발일지에서는 무엇을 연결하고 어떤 선택지를 추가했는지까지 기록해 둡니다.
