# vica 개발일지: 채팅의 작업 범위와 도구 연결 정리

2026년 11월 12일의 최근 커밋 4개에서는 채팅이 맡는 일을 넓히고, 플러그인과 서비스로 요청을 연결하는 부분을 손봤습니다. 채팅이 직접 수정 작업을 하거나 링크를 읽고, 필요한 플러그인과 서비스를 사용하는 기능이 중심입니다. 여기에 플러그인 이름을 찾는 방식과 일부 도구의 라우팅, 측정 기록도 함께 정리했습니다.

이번 일지는 커밋 메시지에서 확인할 수 있는 변경을 기능별로 묶었습니다. 구체적인 구현 방식이나 테스트 결과는 제공된 내용에 없어서, 확인된 작업 범위와 그 의미를 구분해 적어보겠습니다.

## 채팅에서 수정과 외부 도구 사용까지

채팅 영역에는 직접 고치기, 링크 읽기, 플러그인과 서비스 사용 기능이 추가됐습니다. 대화 중 들어온 요청에 따라 채팅이 수행할 수 있는 작업의 종류가 늘어난 셈입니다. 수정할 대상이 있거나 링크의 내용을 읽어야 하는 요청, 외부 기능을 써야 하는 요청을 채팅에서 다루도록 범위를 넓혔습니다.

여기서 ‘직접 고친다’는 기능의 구체적인 수정 대상과 권한 범위는 커밋 메시지만으로 알 수 없습니다. 링크 역시 어떤 형식과 접근 조건까지 지원하는지는 확인되지 않았습니다. 따라서 모든 자료를 읽거나 원하는 대상을 제한 없이 수정할 수 있다고 설명하기는 어렵습니다. 이번 변경에서는 해당 작업을 채팅의 기능으로 추가했다는 점까지 확인할 수 있습니다.

서비스 요청을 누가 맡는지도 정리했습니다. **Vica가 직접 연결한 서비스에 대한 요청은 채팅 에이전트가 담당하도록 했습니다.** 플러그인과 서비스를 사용할 수 있게 한 변경이 작업 범위를 넓혔다면, 이 변경은 그중 직접 연결된 서비스의 담당 주체를 명확히 한 작업입니다. 모든 서비스 요청에 같은 규칙이 적용된다고 확대해서 읽지 않고, ‘Vica가 직접 연결한 서비스’라는 조건을 붙여 이해하는 것이 정확합니다.

## 사람이 적은 이름으로 플러그인 찾기

플러그인 영역에서는 사용자가 이름을 적는 방식에 맞춰 플러그인을 찾도록 수정했습니다. 채팅에 플러그인 사용 기능이 생겨도, 이름을 찾는 단계에서 요청한 대상을 식별하지 못하면 실제 사용으로 이어지기 어렵습니다. 이번 이름 검색 수정은 채팅의 도구 사용 기능과 맞닿아 있는 작업입니다.

다만 어떤 표기 차이를 처리하는지는 제공된 메시지에 드러나지 않습니다. 띄어쓰기나 대소문자, 별칭, 오타까지 모두 지원한다고 말할 근거는 없습니다. 확인할 수 있는 핵심은 **플러그인 이름을 사람이 입력하는 방식에 맞춰 찾도록 고쳤다**는 점입니다. 지원 범위를 자세히 소개하려면 실제 입력 예시와 검색 결과를 함께 확인해야 합니다.

## 도구 라우팅과 측정 기록 정리

vibe 영역에서는 미리 찾기·체커·계정 도구의 라우팅과 측정 기록을 갱신했습니다. 채팅과 서비스 연결이 기능의 범위와 담당 주체를 다룬다면, 이쪽은 개별 도구로 요청을 보내는 경로와 기록을 정리한 변경입니다. 사용자에게 보이는 기능 설명만으로는 드러나지 않는 연결 부분도 이번 작업에 포함됐습니다.

측정 기록을 갱신했다는 사실과 성능이 좋아졌다는 판단은 구분해야 합니다. 제공된 내용에는 측정 항목이나 수치, 이전 결과와의 비교가 없습니다. 속도나 정확도가 개선됐다고 단정하지 않고, 라우팅 변경과 함께 측정 기록을 갱신했다는 수준으로 남깁니다.

이번 커밋들은 채팅의 실행 기능, 서비스 요청의 담당 주체, 플러그인 이름 검색, 도구 라우팅을 각각 다뤘습니다. 기능이 추가된 만큼 실제 사용 범위를 설명할 때도 조건을 정확히 붙일 필요가 있습니다. 특히 직접 수정의 대상, 링크 접근 범위, 플러그인 이름의 허용 표기는 구현과 테스트를 확인해야 더 구체적으로 안내할 수 있겠습니다.
