# vica 개발일지: 데스크톱 작업 공간과 원격 응답 흐름 정리

11월 2~3일의 최근 커밋 16개에서는 데스크톱 작업 공간을 정리하고, PC에서 진행하는 컴퓨터 유즈 작업에 휴대폰과 태블릿으로 대응하는 흐름을 넓혔습니다. 프로젝트와 파일을 다루는 기능부터 사용자 확인을 기다리는 방식까지 함께 손봤습니다. 이번 변경을 작업 공간, 응답 대기, 원격 연결, 평가로 나눠 소개해 드릴게요.

## 프로젝트와 파일을 한곳에서 다루기

왼쪽 사이드바는 프로젝트·대화·파일을 각각 펼치고 접는 아코디언 구조로 바꿨습니다. 프로젝트를 그룹으로 묶어 관리하는 기능도 더했습니다. 여러 프로젝트를 오갈 때 목록을 구분하고, 필요한 영역을 펼쳐 보는 구성이 됐습니다.

파일을 다루는 기능도 늘었습니다. 프로젝트 제거와 파일 삭제, 외부 파일 끌어 놓기, 다른 앱으로 열기를 추가하고 관련 기능을 영역별로 정리했습니다. 프로젝트 목록을 관리하는 일과 실제 파일을 다루는 일을 데스크톱 안에서 이어 갈 수 있도록 범위를 넓힌 변경입니다.

오른쪽에는 상태 패널과 작업 기록을 넣었습니다. 첫 실행 환영 화면을 추가하고 헤더와 글자 크기도 다듬었습니다. 채팅에는 비카 발바닥 로딩 표시를 달아 응답을 기다리는 상태를 보여 주도록 했습니다. 다만 이런 화면 변경으로 실제 사용이 얼마나 편해졌는지는 커밋 목록만으로 판단하기 어려워요. 이번 기록에서는 바뀐 구성과 추가한 기능까지 말씀드리겠습니다.

## 사용자가 답해야 할 일을 모으기

모든 프로젝트에서 사용자를 기다리는 항목을 ‘응답 대기’로 모았습니다. 여기에 실패 항목과 읽을 것도 포함하고, 표시 범위를 휴대폰·태블릿·헤더까지 넓혔습니다. 프로젝트별 화면에 들어가 확인하던 대상을 한데 모아 볼 수 있도록 정리한 셈입니다.

대화의 시작과 전환 흐름도 손봤습니다. 첫 실행에서 선택한 폴더를 바로 등록하고, 토론은 사용자가 요청했을 때만 열도록 바꿨습니다. 회의가 끝난 뒤에는 1:1 대화로 이어지게 했습니다. 폴더 등록 시점과 토론을 여는 조건, 회의 이후의 대화 방식을 각각 명확히 한 변경입니다.

## PC 밖에서도 확인하고 멈추기

원격 기능에서는 태블릿이 짝지은 PC의 앱 화면을 받아 그대로 사용할 수 있게 됐습니다. 이를 위한 태블릿 원격 통로를 마련했고, 컴퓨터 유즈에 필요한 로그인 정보를 사용자에게 받아 저장하는 기능도 추가했습니다.

컴퓨터 유즈가 확인을 요청하면 원격 기기에서도 답하거나 작업을 정지할 수 있습니다. 원격 확인은 몇 분까지 기다릴 수 있도록 바꿨고, 답을 기다리는 상황에는 잠든 휴대폰으로 푸시 알림을 보내도록 했습니다. 확인 요청을 전달하는 데서 그치지 않고, 사용자가 응답하거나 중단하는 경로까지 연결했습니다.

원격 기기가 연결된 동안에는 PC의 잠자기와 화면 잠금을 막도록 했습니다. 원격 작업을 이어 가기 위한 동작이지만, 화면 잠금에도 영향을 주는 변경이라는 점은 함께 짚어 둘 필요가 있습니다. 설정 화면은 양쪽 정렬로 다듬었습니다.

## 평가 범위와 문서 업데이트

컴퓨터 유즈 평가에는 실제 업무 과제, 악성 지시, 확인 거부 과제를 추가하고 실격 판정도 넣었습니다. 작업 수행뿐 아니라 악성 지시나 확인 거부가 포함된 상황도 평가 대상에 포함했습니다. 다만 커밋 정보에는 평가 결과나 통과율이 없으므로, 이번 변경만으로 성능이나 안전성이 검증됐다고 말할 수는 없습니다.

README도 11월 3일 기준으로 갱신했습니다. 이번 작업에서 눈에 띄는 연결점은 데스크톱의 작업 상태를 정리하고, 사용자가 답해야 하는 순간을 다른 기기까지 이어 놓았다는 점입니다. 실제 사용성과 원격 연결의 안정성은 구현 내역과 구분해서 확인해야 할 부분으로 남아 있습니다.
