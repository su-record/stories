# vica 개발일지: 채팅 대기 구조와 직접 로그인 정리

2026년 11월 2일의 최근 커밋 20개에서는 채팅 실행 방식과 직접 로그인 흐름을 집중적으로 다뤘습니다. 0.0.5 릴리스 커밋 이후, 프로젝트 폴더에 세션을 켜 두는 구조부터 작업 중 입력 처리, 봇 구성까지 손봤습니다. 이번 기록은 커밋 메시지에 드러난 변경을 기준으로 정리했습니다. 지연 측정과 호출 시험 기록은 있지만, 구체적인 수치나 결과가 주어지지 않아 성능 개선 폭까지 단정하지는 않겠습니다.

## 채팅 세션을 준비하고, 실행 흐름을 다듬었습니다

채팅에서는 Muse를 프로젝트 폴더에 켜 두고 사용하는 구조를 추가했습니다. 이어서 이미 켜 둔 Muse 세션도 프로젝트 폴더에서 시작하도록 수정했습니다. 세션을 유지하는 기능과 그 세션이 시작되는 위치를 함께 다룬 셈입니다. 채팅 지연 측정과 데몬 대기 구조에 관한 결정도 문서로 남겼습니다.

Claude를 대기시키는 기능도 추가했습니다. 직접 연결과 Claude 대기의 실측 기록을 별도로 남겨, 연결 방식과 대기 구조를 판단한 근거를 문서에서 확인할 수 있도록 했습니다. 다만 이번 커밋 목록만으로는 어떤 방식이 얼마나 빨랐는지까지 비교하기 어렵습니다.

실행 중 사용자 입력을 다루는 방식도 바꿨습니다. 작업 중 들어온 입력은 대기열로 받고, Esc로 작업을 멈출 수 있게 했습니다. 에이전트 커서는 작업 중인 화면으로 옮겼고, 공통 판단 시각화와 채팅 실행 경계도 안정화했습니다. 대기, 실행, 중단을 각각 다룬 변경이라는 점에서 함께 묶어 볼 수 있습니다.

## 봇 설정과 작업 연결을 확장했습니다

봇은 이름과 페르소나로 구성하고 작업에 연결할 수 있도록 했습니다. 봇의 설정을 작업 연결까지 이어 준 변경입니다. 역할마다 추론 강도를 선택하는 설정도 추가했습니다. 어떤 역할에 어느 강도를 적용할지는 커밋 메시지에 나오지 않으므로, 이번에는 선택 기능이 생겼다는 범위까지만 정리하겠습니다.

채팅 버튼에는 눌림 효과를 넣었습니다. 실행 구조를 바꾸는 작업과 함께, 사용자가 버튼을 눌렀을 때 화면에서 확인할 수 있는 반응도 챙겼습니다.

## 직접 로그인 범위를 조정했습니다

데스크톱에서는 ChatGPT, Meta, Grok 직접 로그인과 호출 시험을 추가한 뒤, 후속 수정에서 Meta를 직접 로그인 대상에서 뺐습니다. 따라서 처음 추가한 목록을 그대로 현재 지원 범위로 소개하면 부정확합니다. 이번 기록에서 확인되는 흐름은 연결 대상을 시험하고, 그 뒤 범위를 조정했다는 것입니다.

직접 로그인 승인 코드에는 복사 버튼을 달았고, 채팅에서는 회사 로그인으로 바로 답하는 기능을 추가했습니다. 에이전트 목록에는 열 제목을 붙였습니다. 로그인 정보를 옮기는 단계와 목록을 읽는 화면을 각각 손본 변경입니다. 직접 로그인 범위와 채팅 우선순위에 관한 판단도 문서로 남겼습니다.

## 개발 도구와 지식 문서를 맞췄습니다

개발 스크립트는 Python에서 Node로 옮겼습니다. 이에 맞춰 지식 문서의 검사 명령도 Node 스크립트 기준으로 고쳤습니다. 실행 도구를 바꾸는 데서 끝내지 않고, 문서에 적힌 명령까지 함께 맞춘 부분입니다.

정리 작업도 이어졌습니다. `poc` 폴더를 삭제하고, 실수로 커밋된 시험 파일은 추적에서 제외했습니다. OpenMausBot 분석과 코드 지도도 갱신했습니다.

이번 변경에서는 채팅 기능 추가와 실행 구조 정리가 나란히 진행됐습니다. 봇 구성과 작업 연결을 넓히는 한편, 세션 시작 위치와 입력 대기열, 중단 동작을 구체화했습니다. 직접 로그인은 추가 뒤 제외된 대상도 있었던 만큼, 다음 기록에서도 최초 구현과 후속 조정을 구분해 소개하겠습니다.
