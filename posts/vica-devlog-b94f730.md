# vica 개발일지: 모델 설정과 판단 경로 정리

2026년 11월 26일에는 vica의 모델 선택 화면, OpenAI 판단 모델의 로그인 경로, Solar 모델의 컨텍스트 설정을 손봤습니다. 관련 지식 문서에는 변경 내용과 실제 일 시험을 기록하고, 이 윈도 PC에서 사용하는 실행 환경도 명시했습니다. 이번 다섯 커밋은 설정·인증·모델 사양·개발 환경으로 나눠 살펴보겠습니다.

## 모델 설정: 종류별로 빠짐없이 보여주기

API 키 모델은 종류별로 모두 보이도록 수정했습니다. 모델을 고르는 화면에서는 선택할 수 있는 항목을 빠짐없이 확인할 수 있어야 합니다. 이번 변경은 그 표시 범위를 바로잡는 데 초점을 맞췄습니다.

Kimi와 Kimi Code는 한 칸으로 합쳤습니다. 종류별 모델을 모두 보여주는 작업과 함께, 두 항목을 설정 화면에서 묶어 표시하도록 정리한 셈입니다. 다만 화면에서 한 칸으로 합쳤다는 사실을 두 모델의 기능이나 인증 방식까지 같아졌다는 뜻으로 넓혀 설명하지는 않겠습니다. 이번 기록으로 확인할 수 있는 변화는 모델 목록의 표시 범위와 항목 구성입니다.

설정 화면은 작은 수정도 사용자가 모델을 찾는 방식에 영향을 줍니다. 그래서 지식 문서에도 키 모델의 종류를 기록해, 화면 구성과 관련 설명을 함께 남겼습니다.

## 판단 모델: ChatGPT 로그인 경로 추가

OpenAI 판단 모델은 ChatGPT 로그인으로도 사용할 수 있게 했습니다. 판단 모델을 이용하는 경로에 로그인 방식을 추가한 것이 이번 기능 변경의 핵심입니다.

여기서 변경 범위는 ‘OpenAI 판단 모델’입니다. 일반 대화나 다른 제공자의 모델까지 로그인 지원이 확대됐다고 볼 근거는 없습니다. 로그인으로 판단 모델을 쓸 수 있다는 점은 분명히 하되, 지원 범위를 실제 변경보다 넓게 소개하지 않으려 합니다.

관련 지식 문서에는 로그인 판단에 관한 내용도 기록했습니다. 기능을 추가한 코드와 그 기능을 설명하는 기록을 함께 남겨, 이후 판단 경로를 살펴볼 때 참고할 수 있게 했습니다.

## Solar: 공식 문서에 맞춘 512K 컨텍스트

Upstage의 Solar Mini 4.5 Preview는 컨텍스트를 512K로 보도록 수정했습니다. 이 값의 기준은 공식 문서입니다. 모델 사양에 해당하는 수치인 만큼, 근거를 명확히 둔 수정입니다.

컨텍스트 크기와 실제 작업에서의 결과는 구분해서 봐야 합니다. 이번 수정으로 말할 수 있는 것은 vica가 해당 모델의 컨텍스트를 공식 문서에 맞춰 512K로 다룬다는 점입니다. 긴 입력을 넣었을 때의 응답 품질이나 작업 성공률까지 이 수치만으로 설명할 수는 없습니다.

지식 문서에는 Solar 컨텍스트와 실제 일 시험도 기록했습니다. 다만 제공된 커밋 정보에는 시험 조건과 결과가 없어서, 여기서는 성능이 좋아졌다거나 특정 작업을 통과했다고 단정하지 않겠습니다.

## 개발 환경: 이 윈도 PC는 개발판만 사용

환경 문서에는 이 윈도 PC가 배포판 없이 개발판만 사용한다고 명시했습니다. 어느 실행본을 기준으로 작업하는지 남겨두는 기록입니다. 이후 이 PC의 동작을 확인할 때도 개발판이라는 전제에서 출발할 수 있습니다.

이 설명은 해당 PC에 한정됩니다. vica 전체의 배포 방식을 바꾸거나, 다른 환경에서도 배포판을 사용하지 않는다는 의미는 아닙니다.

이번 작업에서는 모델 목록의 표시 범위를 고치고, 판단 모델의 로그인 경로를 추가했으며, Solar의 컨텍스트 값을 공식 사양에 맞췄습니다. 문서에는 관련 지식과 로컬 실행 환경을 남겼습니다. 기능 변경과 문서 기록을 함께 묶되, 시험 결과처럼 아직 이 커밋 정보만으로 확인할 수 없는 부분은 구분해 두었습니다.
