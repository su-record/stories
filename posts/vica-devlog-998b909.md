# vica 개발일지: 모델 선택 기준과 답변 경로 점검

2026년 11월 1일, vica에서는 모델을 고르는 기준과 답변 경로를 점검하는 기능을 추가했습니다. 최근 커밋 세 개를 영역별로 묶으면, 모델 목록과 자동 선택을 다룬 작업, 그리고 시험지로 판단과 답을 평가해 틀린 경로를 고치는 작업으로 나뉩니다. 이번 기록은 커밋 메시지에서 확인할 수 있는 변경을 중심으로 정리했습니다.

## 모델 관리: 목록을 갱신하고, 점수와 난이도로 선택하기

모델 영역에서는 목록 관리와 선택 로직을 함께 손봤습니다. 모델 목록은 JSON으로 관리하고 매주 갱신하도록 했습니다. 목록을 어떤 형식으로 유지할지, 얼마나 자주 갱신할지를 정한 셈입니다.

모델을 자동으로 선택하는 기능도 추가했습니다. 선택에 쓰는 기준은 벤치마크 점수와 난이도입니다. 모델의 벤치 점수만 보는 데서 그치지 않고, 난이도도 선택 기준에 포함했다는 점이 이번 변경의 핵심입니다. 다만 난이도를 어떻게 산정하는지, 두 기준을 어떤 비중으로 반영하는지는 커밋 메시지만으로 알 수 없습니다.

두 작업은 모델 관리라는 같은 영역에 속하지만 맡은 역할은 다릅니다. JSON 목록과 주간 갱신은 모델 정보를 유지하는 쪽이고, 자동 선택은 기준에 따라 모델을 고르는 쪽입니다. 목록을 관리하는 일과 선택 규칙을 마련하는 일을 나눠 보면 이번 변경의 범위가 좀 더 분명해집니다.

아직은 자동 선택 기능이 생겼다는 사실과, 그 선택이 실제로 좋은 결과를 낸다는 판단을 구분해야 합니다. 벤치 점수와 난이도를 반영했다고 해서 응답 품질이나 비용이 얼마나 달라졌는지까지 말할 수는 없습니다. 그런 효과를 확인하려면 선택 결과와 실제 응답을 비교한 기록이 필요합니다.

## 채팅: 시험지로 판단과 답을 평가하고 경로 고치기

채팅 영역에는 시험지를 활용해 판단과 답을 평가하고, 틀린 경로를 고치는 기능을 추가했습니다. 커밋에 적힌 평가 대상은 ‘판단’과 ‘답’입니다. 최종 답과 함께 판단도 점검 대상으로 삼았다는 점을 눈여겨볼 만합니다.

이번 작업에는 평가뿐 아니라 잘못된 경로를 수정하는 기능도 포함돼 있습니다. 다만 여기서 말하는 경로가 구체적으로 무엇인지, 오류를 어떤 기준으로 판정하는지, 수정이 어느 범위까지 적용되는지는 제공된 정보에 없습니다. 따라서 답변 과정을 모두 추적한다거나, 평가를 반복할수록 성능이 자동으로 좋아진다고 설명하기는 어렵습니다.

현재 확인할 수 있는 변화는 시험지를 이용한 평가와 경로 수정이 채팅 기능에 들어왔다는 데까지입니다. 실제 동작을 더 살펴볼 때는 판단이 틀린 경우와 답이 틀린 경우를 어떻게 구분하는지, 경로를 고친 뒤 같은 시험지에서 결과가 달라지는지를 확인하고 싶습니다. 기능의 효과를 설명하려면 이런 비교가 뒷받침돼야 하니까요.

## 이번 변경에서 확인한 것과 남은 것

이번 세 커밋은 모델을 선택하는 단계와 채팅의 판단·답을 점검하는 단계를 각각 다룹니다. 모델 쪽에는 목록의 관리 형식과 갱신 주기, 자동 선택 기준이 생겼고, 채팅 쪽에는 시험지를 통한 평가와 경로 수정이 추가됐습니다.

두 영역이 실제로 어떻게 연결되는지는 아직 단정하지 않겠습니다. 시험지 평가 결과가 모델의 벤치 점수에 반영되는지, 경로 수정에 모델 재선택이 포함되는지도 별도 확인이 필요합니다. 이번 개발일지에서는 구현된 기능의 범위를 기록하고, 품질 개선의 크기는 실제 평가 결과를 확인한 뒤 이야기하려고 합니다.
