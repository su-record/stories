# vica 개발일지: EXAONE API와 시대 테마, 화면·출력 관련 수정

2026년 11월 10일의 최근 커밋 3개에서는 LG EXAONE API 추가와 시대 테마 작업을 진행했습니다. 테마는 12종을 추가했고, 관련 스크린샷은 운영체제와 출시 연도를 기준으로 정리했습니다. 생각 깊이 막대의 번짐, 커밋 관련 결함, 터미널 대량 출력도 함께 손봤습니다. 이번 일지는 커밋 순서 대신 API, 테마, 화면과 출력이라는 영역으로 나눠 정리해 보겠습니다.

## 모델 연동: LG EXAONE API 추가

모델 연동 영역에서는 LG EXAONE API를 추가했습니다. 이번 변경에서 새로 이름을 올린 외부 API입니다. 테마와 화면 수정이 함께 있었지만, 모델 API 연동은 별도의 기능 확장으로 구분할 수 있습니다.

다만 API를 추가했다는 사실과 실제로 어떤 기능까지 사용할 수 있는지는 구분해서 말씀드리는 게 맞겠습니다. 커밋 요약에는 지원 모델 목록이나 인증 설정, 호출 옵션이 나와 있지 않습니다. 따라서 이번 기록에서는 EXAONE API를 추가했다는 범위까지만 다룹니다. 성능이나 응답 품질 역시 이 변경만으로 평가하지 않겠습니다.

## 테마: 시대 테마 12종과 스크린샷 정리

테마 영역에서는 시대 테마 12종을 추가했습니다. 이와 함께 테마 스크린샷을 OS와 출시 연도에 따라 정리했습니다. 테마 자체를 늘리는 작업과, 테마를 보여 주는 자료의 분류 기준을 잡는 작업이 같은 날 이뤄졌습니다.

스크린샷에 적용한 두 기준은 역할이 조금 다릅니다. OS는 어떤 운영체제에 해당하는 자료인지 구분하고, 출시 연도는 시기별로 살펴볼 기준이 됩니다. 시대 테마를 다루는 만큼, 이미지 자료에도 운영체제와 시간이라는 맥락을 붙였다고 볼 수 있겠습니다.

다만 12종의 개별 이름이나 각 테마가 재현한 화면 요소는 커밋 요약에 포함돼 있지 않습니다. 이번 글에서 특정 운영체제의 외형을 얼마나 충실하게 구현했는지까지 소개하기는 어렵습니다. 확인할 수 있는 변화는 테마의 수와 스크린샷의 정리 기준입니다.

## 화면 표현: 생각 깊이 막대 번짐 제거

화면에서는 생각 깊이 막대의 번짐을 제거했습니다. 테마 추가와는 구분되는, 특정 UI 요소의 표시 문제를 다룬 수정입니다.

이 변경은 범위를 좁혀 기록하려고 합니다. 막대의 번짐을 없앴다는 내용이지, 생각 깊이의 동작이나 설정 범위를 바꿨다는 내용은 아닙니다. 화면 표현을 손본 사실을 기능 로직의 변화로 넓혀 설명하지 않는 편이 정확하겠습니다. 같은 이유로 모든 테마에서 표시 문제가 해결됐다고 단정할 근거도 아직 없습니다.

## 결함과 출력: 커밋·터미널 관련 후속 수정

커밋 관련 결함과 터미널 대량 출력도 수정 대상에 포함됐습니다. 여기에 검토 이후의 후속 수정까지 반영했습니다. 새 기능과 테마를 추가하는 작업에 더해, 기존 동작에서 손볼 부분과 검토 내용을 함께 다룬 셈입니다.

이 영역은 커밋 요약만으로 세부 내용을 풀어 쓰기에는 한계가 있습니다. 어떤 조건에서 커밋 결함이 발생했는지, 대량 출력에서 무엇이 문제였는지, 검토 후 어느 부분을 바꿨는지는 드러나지 않습니다. 그래서 속도 개선이나 출력 누락 방지 같은 구체적인 효과는 이번 기록에 넣지 않았습니다.

이번 세 커밋의 변화는 EXAONE API와 시대 테마를 추가한 부분, 스크린샷 자료를 정리한 부분, 화면·커밋·출력 관련 문제를 수정한 부분으로 나뉩니다. 기능 추가의 규모와 수정의 효과를 같은 말로 묶기보다는, 확인된 변경 범위를 각각 남겨 두겠습니다. 세부 동작과 해결 여부는 코드와 검증 결과를 함께 확인해야 더 정확히 설명할 수 있습니다.
