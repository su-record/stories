# vica 개발일지: 컴퓨터 조작의 역할 분담과 사용량 화면 정리

11월 20~21일 vica에서는 컴퓨터 조작을 맡는 모델의 진행 순서를 바꾸고, 클릭 대상 확인과 결과 검증 시점을 손봤습니다. 선택한 판단 모델들이 함께 답하고 작업 도중에도 개입할 수 있도록 했으며, 사용량 화면에서는 한도를 다 쓴 연결을 숨겼습니다. 이번 다섯 커밋은 모델 간 협업, 조작 확인, 사용량 표시라는 세 영역으로 묶어 살펴보겠습니다.

## 판단 모델이 먼저 진행하고 작업 모델이 이어받습니다

데스크톱의 컴퓨터 조작 흐름은 판단 모델이 먼저 진행하고, 작업 모델이 그 뒤를 이어받는 순서로 바뀌었습니다. 두 모델 사이에 선후 관계를 둔 변경입니다. 컴퓨터 조작을 시작하는 단계에서 판단 모델이 먼저 관여한다는 점이 이번 역할 분담의 핵심입니다.

판단 모델을 여러 개 체크했을 때의 동작도 함께 달라졌습니다. 체크한 판단 모델은 모두 함께 답하며, 작업이 진행되는 중에도 끼어들 수 있습니다. 판단 모델의 참여 범위가 작업 시작 시점에만 머물지 않고 진행 중인 작업까지 이어진 셈입니다.

두 변경을 묶어서 보면, 먼저 판단 모델이 진행하고 작업 모델이 이어받되 이후에도 판단 모델이 참여할 수 있는 흐름입니다. 다만 커밋 메시지만으로는 여러 모델의 답이 엇갈릴 때 무엇을 우선하는지, 개입한 뒤 작업을 어떻게 이어가는지까지 알 수는 없습니다. 이번 기록에서는 참여 순서와 범위가 달라졌다는 데 초점을 맞추겠습니다.

## 클릭 대상을 확인하고 결과를 더 일찍 검증합니다

컴퓨터 조작 영역에서는 클릭 대상을 확인하고 결과 검증을 앞당겼습니다. 클릭할 대상의 확인과 조작 결과의 검증을 함께 손본 변경입니다.

이 부분은 모델 간 역할 분담과 구분해서 볼 필요가 있습니다. 앞선 변경이 누가 먼저 진행하고 언제 참여할 수 있는지를 정했다면, 이번 수정은 실제 조작 과정에서 무엇을 확인할지에 관한 내용입니다. 역할을 나누는 것과 별개로, 클릭 대상과 결과를 확인하는 절차도 다듬었습니다.

결과 검증을 앞당겼다는 방향은 분명하지만, 정확히 어느 단계로 옮겼는지는 제공된 메시지에 나와 있지 않습니다. 클릭 오류가 얼마나 줄었는지, 작업 성공률이 달라졌는지도 아직 이 기록으로 판단할 수는 없습니다. 확인된 변화는 클릭 대상을 살피고 결과를 이전보다 이른 시점에 검증하도록 수정했다는 점입니다.

## 사용량 화면의 노출 기준과 문서 표시를 정리했습니다

사용량 화면에서는 한도를 다 쓴 연결이 보이지 않도록 바꿨습니다. 연결의 사용량 한도 상태가 화면 노출에 반영됩니다. 사용자는 해당 화면에서 이미 한도를 소진한 연결을 보지 않게 됩니다.

다만 화면에서 숨기는 동작과 연결 자체를 삭제하거나 비활성화하는 동작은 구분해야 합니다. 이번 커밋에서 확인할 수 있는 범위는 사용량 화면의 표시 변경까지입니다. 한도가 다시 생겼을 때 어떻게 표시되는지 같은 후속 동작은 메시지만으로 확정하지 않겠습니다.

관련 문서에서는 사용량 한도 기록에 붙어 있던 ‘미커밋’ 표시를 지웠습니다. 화면 동작을 바꾸는 작업과는 성격이 다른, 기록 상태를 정리한 수정입니다. 기능 변경과 문서 정리를 나누어 적어 두면 이번에 실제 동작이 달라진 부분도 더 명확하게 볼 수 있습니다.

이번 작업에서 가장 큰 흐름은 판단 모델의 참여 순서를 바꾸고 범위를 넓히면서, 컴퓨터 조작의 확인 절차도 함께 손봤다는 점입니다. 사용량 영역에서는 한도 소진 상태에 맞춰 화면 표시를 바꿨습니다. 문서에서는 사용량 한도 기록의 ‘미커밋’ 표시를 지웠습니다. 실제 사용 경험이 얼마나 달라졌는지는 추가 확인이 필요하지만, 이번 개발일지에서는 변경된 동작과 아직 확인하지 못한 효과를 구분해 남깁니다.
