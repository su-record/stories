# vica 개발일지: 재연결 시험과 파일 링크 검사, 시맨틱 검색 정비

2026년 11월 8일의 vica 변경은 연결 시험, 에이전트의 파일 편집, 시맨틱 검색, Windows 배포 기록에 걸쳐 있습니다. 이번 네 커밋에서는 새 기능의 범위를 넓히기보다 기존 동작을 확인하는 조건을 다듬고, 편집 경로에서 빠진 검사를 복구했습니다. 검색에는 Qwen용 질의 지침을 반영했고, 문서에는 검증한 Windows 0.1.6 배포 내용을 남겼습니다.

## 재연결 시험: 서버가 읽는 시점까지 연결 유지하기

플랫폼의 재연결 시험에서는 서버가 데이터를 읽을 때까지 클라이언트 연결을 유지하도록 바꿨습니다. 여기서 중요한 기준은 클라이언트가 연결을 끝내는 시점입니다. 시험이 서버의 읽기 동작을 확인하려면, 그 동작이 이뤄지기 전에 클라이언트 연결부터 닫히지 않도록 해야 합니다.

이번 수정은 연결을 유지하는 조건을 서버의 읽기 시점에 맞춘 작업입니다. 재연결 시험에서 확인하려는 동작과 시험 자체의 연결 종료가 엇갈리지 않게 만드는 방향이라고 볼 수 있습니다. 다만 커밋 정보만으로는 기존 시험이 얼마나 자주 실패했는지, 이번 변경 뒤 실패율이 얼마나 줄었는지 알 수 없습니다. 제품의 재연결 처리 전체가 바뀐 것으로 확대하기보다는 시험 조건을 정비한 변경으로 보는 게 정확합니다.

## 에이전트 편집: 파일 링크 거부 검사가 다시 작동하도록

에이전트에서는 언어 서버를 통한 편집 경로의 파일 링크 처리를 수정했습니다. 해당 경로에서 링크를 풀지 않도록 바꿔, 링크를 거부하는 검사가 다시 동작하게 했습니다.

이 변경의 핵심은 경로를 처리하는 순서에 있습니다. 링크 여부를 판단해야 하는 검사에 도달하기 전에 링크를 풀어 버리면, 검사가 확인해야 할 정보에 영향을 줄 수 있습니다. 이번에는 언어 서버 편집 경로에서 그 처리를 하지 않도록 조정해 기존 거부 검사가 제 역할을 하게 했습니다.

범위도 구분해 둘 필요가 있습니다. 확인된 내용은 언어 서버 편집 경로의 수정이며, 모든 파일 접근 경로나 링크 관련 정책을 새로 설계했다는 뜻은 아닙니다. 기존에 두었던 제한이 해당 편집 경로에서도 적용되도록 복구한 작업입니다.

## 시맨틱 검색: Qwen용 질의 지침 반영

시맨틱 검색에는 Qwen용 질의 지침을 반영했습니다. 검색어를 모델에 전달할 때 검색 의도에 맞는 지침을 함께 사용하는 방향의 개선입니다.

다만 제공된 커밋 정보에는 지침의 구체적인 문구나 적용 전후의 검색 결과가 없습니다. 따라서 어떤 유형의 질문에서 효과가 컸는지, 검색 정확도가 얼마나 달라졌는지는 아직 이 기록에서 말하기 어렵습니다. 이번 일지에서는 Qwen을 활용하는 검색 과정에 질의 지침을 반영했다는 구현 변경과, 실제 검색 품질에 대한 평가는 구분해 두겠습니다.

## 배포 문서: 검증한 Windows 0.1.6 기록 남기기

문서에는 검증된 Windows 0.1.6 배포 내용을 기록했습니다. 코드 변경과는 별개로, 확인을 마친 배포 내용을 버전과 운영체제에 연결해 남긴 작업입니다.

이 기록의 범위는 Windows 0.1.6입니다. 다른 운영체제나 이후 버전까지 검증됐다는 의미로 읽어서는 안 됩니다. 구체적인 검증 환경과 절차는 제공된 커밋 정보에 없으므로 여기서 덧붙이지 않았습니다.

이번 변경을 돌아보면 시험과 편집 경로는 각각 서버의 읽기 시점과 링크 검사 조건을 바로잡았고, 검색은 질의 지침을 조정했습니다. 배포 문서에는 확인한 버전의 기록을 보탰습니다. 특히 검색 개선의 효과와 재연결 시험의 안정성은 변경 사실만으로 수치화할 수 없는 만큼, 성과를 단정하지 않고 실제 수정 범위까지 남겨 둡니다.
