# vica 개발일지: 화면을 뺏지 않는 컴퓨터 조작과 대화 탐색

11월 13일부터 16일까지의 최근 커밋 8개에서는 컴퓨터 조작 범위를 넓히고, 사용자의 작업을 방해하지 않도록 동작을 다듬었습니다. 휴대전화에서는 이전 대화를 읽고 답변을 표시하는 방식을 손봤고요. 작업 그룹과 모델 설정, 설치 동작, 릴리스 문서도 함께 정리했습니다.

## 컴퓨터 조작: 뒤에 있는 창까지 다루기

이번 변경에서 비중이 큰 부분은 컴퓨터 조작입니다. 판단 모델이 다음 단계를 고르는 흐름을 넣었습니다. 조작 과정에서 어떤 단계를 밟을지 모델이 선택하도록 구성한 것이죠. 이와 함께 외부 레포 검토에서 나온 추천 사항과 전면 검수에서 지적된 부분을 반영했습니다. 다만 커밋 요약만으로 구체적인 검수 항목이나 조작 성공률까지 설명하기는 어렵습니다.

창을 다루는 방식도 바꿨습니다. 컴퓨터를 조작할 때 화면을 뺏지 않도록 하고, 다른 데스크톱에 있는 창에서도 동작하도록 손봤습니다. 사용자가 보고 있는 화면을 유지하면서 조작할 수 있는 범위를 넓힌 셈입니다.

뒤에 있는 앱에서는 문서를 저장하거나 닫을 수 있게 했습니다. 가려진 웹 기반 앱도 계속 그리도록 켰고요. 창이 보이는지 여부에 따라 앱의 화면 갱신과 조작에 차이가 생길 수 있는 만큼, 가려진 상태도 조작 대상으로 다루는 변경입니다. 그렇다고 모든 앱에서 같은 수준으로 동작한다고 단정할 수는 없습니다.

키 입력은 조금 더 세밀하게 다뤘습니다. 뒤에 있는 목록의 줄에 키를 보낼 수 있도록 고쳤고, 키를 보내기 전에 거절된 경우는 별도 응답으로 구분했습니다. 이 구분 덕분에 입력을 시도한 뒤의 결과와, 입력 자체가 진행되지 않은 상황을 나눠 볼 수 있습니다.

## 휴대전화: 이전 대화 읽기와 답변 표시

휴대전화 쪽에서는 명령 하나로 대화를 거슬러 읽는 기능을 추가했습니다. 이전 내용을 확인하려는 작업을 하나의 명령으로 요청할 수 있게 된 변화입니다. 아이폰 잠금 해제 기능도 함께 넣었습니다.

답변은 마크다운으로 표시하도록 바꿨습니다. 대화 내용을 가져오는 기능과 답을 보여주는 형식을 같은 시기에 손본 셈인데요. 여기서는 잠금 해제가 가능한 조건이나 대화 탐색 범위까지 알려져 있지 않으므로, 지원 범위를 넓혀 해석하지는 않겠습니다.

## 작업 구성과 언어·모델 설정

그룹은 작업용으로 사용할 수 있도록 바꿨습니다. 화면에 들어가는 글은 언어별 객체로 옮겨, 표시 문구를 언어 단위로 다루도록 정리했습니다. 이 변경을 곧바로 새로운 언어 지원으로 볼 수는 없지만, 화면 문구를 관리하는 구조가 달라졌다는 점은 분명합니다.

설정 변경도 있었습니다. `vica-laya`를 끄고, 구글 기본 모델을 Hydrogen으로 바꿨습니다. 모델 변경에 따른 품질이나 속도 비교는 이번 커밋 요약에 없으므로, 여기서는 기본 선택이 바뀌었다는 사실까지만 기록합니다.

## 설치 의도 보존과 유지보수 정리

설치 과정에서는 사용자가 꺼 둔 `Vica-dev`를 다시 켜지 않도록 고쳤습니다. 사용자가 명시적으로 끈 상태를 설치가 되돌리지 않게 한 수정입니다. 기능 추가와 별개로, 설치 이후의 동작이 사용자 선택을 존중하도록 맞췄습니다.

개발 쪽에서는 벤치마크를 뒷단용으로 수정하고 긴 파일을 나눴습니다. 릴리스 문서에는 키체인 암호가 맞지 않을 때 살펴볼 원인과 점검 순서를 적었습니다. 문제가 생겼을 때 확인할 경로를 문서로 남긴 작업입니다.

이번 기록의 중심은 백그라운드 창 조작을 확장하면서 입력 전 거절 같은 상태도 구분한 데 있습니다. 실제 사용에서 얼마나 안정적으로 동작하는지는 커밋만으로 판단하기 어렵습니다. 이번 개발일지에는 구현과 수정으로 확인되는 범위를 담았습니다.
