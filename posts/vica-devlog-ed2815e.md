# vica 개발일지: 데스크톱 사용 흐름과 채팅 제어를 다듬은 0.0.4

2026년 10월 31일, vica는 데스크톱의 선택·확인 기능과 채팅의 완료 근거·프로젝트 쓰기 제어를 손보고 0.0.4로 버전을 올렸습니다. 이번 변경은 화면에 드러나는 기능과 작업을 마무리하는 기준을 함께 다뤘습니다. 최근 커밋 네 개를 사용 흐름에 따라 묶어 정리해 보겠습니다.

## 판단 모델 선택과 사용량 확인

데스크톱에는 판단 모델 선택지와 사용량 팝업을 추가했습니다. 모델을 고르는 부분과 사용량을 확인하는 부분이 같은 날 보강됐습니다. 두 기능은 각각 선택과 확인을 맡지만, 사용자가 데스크톱에서 접하는 정보를 늘렸다는 점에서 함께 소개할 만합니다.

다만 커밋 메시지만으로는 어떤 모델을 선택할 수 있는지, 사용량 팝업이 어떤 항목과 집계 기준을 보여 주는지까지 알 수 없습니다. 이번 기록에서는 선택지와 팝업이 추가됐다는 범위까지만 다루겠습니다. 특정 모델의 성능이나 사용량 수치의 의미는 실제 구현을 확인한 뒤 설명하는 편이 정확하겠습니다.

## 탭 메뉴와 비카 모션

화면 구성에서는 탭 메뉴와 비카 모션을 더했습니다. 탭 메뉴는 메뉴 기능에, 비카 모션은 화면 속 움직임에 해당하는 변경입니다. 데스크톱 기능을 설명할 때 한데 묶기 쉽지만, 사용자가 조작하는 요소와 시각적으로 접하는 요소라는 차이가 있습니다.

탭 메뉴에 담긴 명령이나 모션이 재생되는 조건은 커밋 메시지에 적혀 있지 않습니다. 그래서 탭 관리가 얼마나 편해졌는지, 모션이 어떤 상태를 전달하는지까지 단정하지는 않겠습니다. 이번에는 두 요소가 데스크톱에 추가됐다는 사실을 남기고, 구체적인 사용법과 화면 설명은 별도 확인이 필요한 부분으로 두겠습니다.

## 채팅의 완료 근거와 프로젝트 쓰기 제어

채팅에서는 완료 근거와 프로젝트 쓰기 제어를 강화했습니다. 이 영역에서 짚을 부분은 완료 판단을 뒷받침하는 근거와 프로젝트에 쓰는 동작의 제어를 함께 손봤다는 점입니다.

완료 근거는 작업을 끝냈다고 판단할 때 무엇을 확인하는지와 연결되고, 프로젝트 쓰기 제어는 쓰기 동작을 어떤 조건에서 다루는지와 연결됩니다. 두 항목을 함께 보면 이번 수정이 작업 결과를 판단하는 부분과 프로젝트를 변경하는 부분에 걸쳐 있다는 것을 알 수 있습니다.

다만 구체적인 검사 방식이나 차단 조건은 제공된 기록에 없습니다. 따라서 모든 완료 판단이 검증된다거나 원치 않는 쓰기를 전부 막는다고 말할 수는 없습니다. 안전성과 관련된 변경인 만큼, “강화했다”는 기록을 실제 보장 범위보다 넓게 해석하지 않으려 합니다.

## 업데이트 안내와 설치판 아이콘, 그리고 릴리스

업데이트는 토스트로 알리도록 했습니다. 업데이트 안내가 데스크톱 화면에서 어떤 형식으로 나타나는지 명시된 변경입니다. 다만 알림을 누른 뒤의 동작이나 설치 과정까지 바뀌었다는 내용은 없으므로, 이번에는 안내 방식의 변경으로 구분하겠습니다.

설치판 아이콘도 개발판과 맞췄습니다. 실행 환경에 따라 달랐던 아이콘을 정리한 변경이며, 앞서 추가한 비카 모션과 함께 데스크톱의 시각 요소를 손본 작업에 해당합니다.

릴리스 커밋에서는 버전을 0.0.4로 올렸습니다. 이번 개발 기록에는 모델 선택과 사용량 확인, 탭 메뉴와 모션, 채팅 제어, 업데이트 안내가 담겼습니다. 추가·수정된 범위는 확인할 수 있지만 세부 동작까지 설명할 자료는 제한적입니다. 사용법이나 개선 효과를 더 자세히 소개하려면 각 기능의 구현과 실행 화면을 확인해야겠습니다.
