# vica 개발일지: 음성 대화와 파일 수정 작업, 화면 정리

2026년 11월 5일의 최근 커밋 7개에서는 채팅 입력과 저장 데이터, Codex 파일 수정 작업, 화면 크기별 표시를 손봤습니다. 입력창 마이크로 실시간 음성 대화를 여는 기능을 더했고, 파일을 고치는 작업에도 권한 모드와 진행 표시, 중단을 적용했습니다. 이번 기록은 기능을 추가한 부분과 기존 동작을 바로잡은 부분을 나눠 정리해 보겠습니다.

## 채팅: 음성 대화를 열고, 요청과 저장 데이터를 바로잡기

채팅 입력창의 마이크에서 실시간 음성 대화를 열 수 있도록 했습니다. API 키가 있을 때 사용할 수 있는 기능입니다. 텍스트를 입력하던 자리에서 음성 대화로 넘어가는 진입점이 생겼지만, 키가 필요하다는 조건은 함께 기억해 두셔야 합니다.

채팅 요청에 들어가는 내용도 수정했습니다. 토큰 수가 요청 글에 붙던 문제가 있었고, 이번에 이를 바로잡았습니다. 요청에 포함될 글과 토큰 수 정보가 섞였다는 점에서, 입력 내용을 다루는 경계를 고친 작업입니다. 망가진 저장 대화를 되돌리는 작업도 함께 진행했습니다. 새 대화를 잘 보내는 것뿐 아니라 이미 저장된 대화도 다뤘다는 점을 이번 변경에 남겨 둡니다.

다만 이 수정만으로 저장 대화의 모든 손상 유형을 처리한다고 말할 수는 없습니다. 커밋에서 확인할 수 있는 범위는 요청 글에 토큰 수가 붙던 문제를 고쳤고, 망가진 저장 대화를 되돌렸다는 데까지입니다.

## 파일 수정: 실행 경로와 패치 처리를 함께 정리하기

파일을 고치는 Codex 작업도 앱 서버를 통해 실행하도록 바꿨습니다. 이 경로에서 권한 모드, 진행 표시, 중단을 적용합니다. 파일 수정 작업을 맡겼을 때 어떤 권한으로 실행되는지, 작업이 어디까지 진행됐는지, 멈출 수 있는지를 같은 실행 경로에서 다루게 된 셈입니다.

패치를 적용하는 쪽에서는 여러 파일을 수정하는 `apply_patch`가 새 파일의 흔한 형식 실수를 받아 주도록 손봤습니다. 새 파일을 포함한 수정에서 형식 때문에 걸리던 경우를 다루는 변경입니다. 다만 어떤 형식이든 허용한다는 뜻은 아닙니다. 이번 기록에서는 ‘흔한 형식 실수를 받아 주는 범위가 생겼다’고 표현하는 것이 정확하겠습니다.

두 작업은 파일 수정의 서로 다른 부분을 다룹니다. 앱 서버 변경은 실행 중 권한과 상태를 관리하는 쪽이고, `apply_patch` 수정은 전달받은 패치를 적용하는 쪽입니다.

## 화면: 좁은 폭의 배치와 내용 표시 다듬기

태블릿 폭에서는 패널을 띄우고 입력창 도구줄을 줄이도록 조정했습니다. 화면 폭에 맞춰 패널 배치와 도구줄이 차지하는 공간을 손본 작업입니다. 다크 테마에서는 화면의 층 표현을 바로잡았고, 표와 코드 표시도 함께 수정했습니다. 배치뿐 아니라 대화 안에 담긴 내용을 보여 주는 방식까지 정리했습니다.

휴대폰의 경로 줄에서는 컴퓨터 이름을 가능한 한 전부 보여 주도록 바꿨습니다. 공간이 모자랄 때만 말줄임을 적용합니다. 짧게 표시하는 것을 우선하기보다, 들어갈 수 있는 이름은 끝까지 보여 주는 기준으로 바꾼 점이 핵심입니다.

## 측정: 반복 횟수와 과제 조건 남기기

채팅 테스트에는 5회 반복 측정과 함께 측정 과제의 문구·지식을 기록했습니다. 반복 횟수뿐 아니라 어떤 과제로 측정했는지도 남긴 변경입니다. 이후 결과를 비교하려면 수치와 함께 측정 조건을 확인할 수 있어야 하니까요.

이번 커밋 목록에는 구체적인 측정 결과가 없어 속도나 품질이 얼마나 달라졌는지는 판단하지 않았습니다. 이번 개발일지에는 음성 대화의 진입점, 파일 수정의 실행 관리, 요청·저장 데이터와 화면 표시의 수정, 그리고 측정 조건을 기록했다는 사실까지 담았습니다.
