# Vica 개발일지: 채팅 작업 흐름과 에이전트 점검, 업데이트 수정

2026년 11월 5일 Vica의 최근 커밋 5개에서는 채팅에서 작업을 확인하고 마무리하는 흐름, 에이전트의 대화 관리와 진단, 앱 업데이트 방식을 손봤습니다. 기능을 더하는 한편, 일반 메시지 전송이 막히거나 업데이트 뒤 Dock에 Vica가 두 개 나타나는 문제도 고쳤습니다. 이번 기록은 기능별로 달라진 점을 묶어 정리했습니다.

## 채팅에서 작업 상태와 마무리를 확인하기

채팅 답변 아래에 커밋 버튼을 추가했습니다. 답변을 확인한 뒤 커밋으로 이어지는 동작을 답변 가까이에 배치한 변화입니다. 다만 버튼을 추가했다는 사실과 커밋 과정 전체를 자동화했다는 것은 구분해야 합니다. 이번 기록에서 확인할 수 있는 범위는 답변 아래에 커밋 진입점을 마련했다는 데까지입니다.

작업 내용을 살펴보는 화면에는 요구사항 점검, 작업자별 파일, 진행 막대를 더했습니다. 요구사항을 확인하는 기능과 작업자별 파일·진행 상태를 보는 요소를 함께 추가해, 채팅에서 결과뿐 아니라 작업 과정도 살펴볼 수 있도록 했습니다. 여러 작업자의 작업을 확인할 때는 누가 어떤 파일을 다루는지 구분하는 정보가 특히 필요합니다.

채팅 영역에는 지침 번역 작업도 포함했습니다. 번역의 세부 범위나 품질 검토 결과는 커밋 정보에 없으므로, 이번에는 번역 작업을 추가했다는 수준으로 기록해 둡니다.

## 에이전트의 긴 대화 관리와 쓰기 후 진단

에이전트 쪽에는 긴 대화를 압축하는 기능을 넣었습니다. 대화가 길어졌을 때 누적된 내용을 다루는 방식을 보완한 작업입니다. 압축 과정에서 어떤 정보를 남기는지, 실제로 대화 길이나 처리 비용이 얼마나 줄었는지는 이번 커밋 요약만으로 판단하기 어렵습니다.

쓰기 작업 뒤에는 자동 진단을 수행하도록 했습니다. 쓰기를 마친 다음 진단이 이어지도록 연결한 점이 핵심입니다. 다만 자동 진단이 모든 문제를 찾아내거나 수정까지 보장하는 것은 아니므로, 기능 추가와 진단 효과는 나누어 봐야 합니다.

회사별 지시문과 도구 설명도 더하고, 지침 영어본을 추가했습니다. 에이전트가 참고하는 지시와 도구 정보를 보강한 영역입니다. 채팅의 지침 번역 작업과 함께 보면, 이번 변경에는 기능 구현뿐 아니라 지침을 정리하고 다른 언어로 제공하는 작업도 포함돼 있습니다.

## 평가 자료 보강과 메시지 전송 오류 수정

채팅 테스트에는 어려운 측정 과제 5개와 개선 전후 결과, Haiku 결과를 추가했습니다. 변경 사항을 비교해 볼 자료를 늘렸다는 점에서 의미가 있습니다. 다만 구체적인 점수나 과제별 결과가 주어지지 않았기 때문에, 성능이 얼마나 좋아졌는지 또는 어떤 모델이 더 나았는지는 여기서 단정하지 않겠습니다.

기본 동작을 막던 오류도 수정했습니다. 전송 함수에서 `cowork`를 재선언해 일반 메시지를 보내지 못하던 문제를 고쳤고, lint 오류도 함께 정리했습니다. 작업 관련 기능을 늘리는 것과 별개로, 일반 채팅을 정상적으로 보낼 수 있어야 한다는 점에서 짚고 넘어갈 수정입니다.

## 업데이트 뒤 Dock 중복 문제 줄이기

앱 안에서 업데이트한 뒤 Dock에 Vica가 두 개 생기던 문제는 앱 교체 방식을 바꿔 대응했습니다. 앱 폴더 자체는 유지하고 그 안의 내용만 교체하도록 수정했습니다.

이번 업데이트 수정은 화면 요소를 추가한 작업은 아니지만, 앱을 갱신한 뒤에도 기존 실행 환경을 이어 가기 위한 변경입니다. 실제 배포 환경에서도 중복 현상이 사라지는지는 업데이트 후 확인할 항목으로 남습니다.
