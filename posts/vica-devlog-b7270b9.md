# vica 개발일지: 브라우저 작업 확장과 권한 확인, Windows 설정 안내

2026년 11월 23일의 vica 변경은 브라우저에서 처리하는 작업을 늘리고, 위험한 도구 사용에는 확인 절차를 유지하는 데 초점을 맞췄습니다. Windows 설정에서는 Aside를 알아보고 Ego 설치를 안내하도록 했습니다. 이번 일지는 최근 커밋 네 개를 브라우저 작업, 데스크톱 권한, 설정 안내와 분석 기록으로 묶어 정리했습니다.

## 브라우저에서 파일과 표까지 다루기

computer 영역에는 브라우저에서 파일을 올리고 내려받는 기능, 기다리기, 표 읽기가 들어갔습니다. 브라우저 작업 범위가 파일 입출력과 페이지 안의 데이터 읽기로 넓어진 셈입니다.

파일 업로드와 다운로드는 서로 반대 방향의 작업이지만, 브라우저를 통해 파일을 주고받는다는 점에서 함께 볼 수 있습니다. 표 읽기는 페이지 내용을 표 형태로 다루는 작업이고요. 이번 변경으로 브라우저에서 사용할 수 있는 작업의 종류가 더 구체적으로 갖춰졌습니다.

‘기다리기’도 별도의 작업으로 추가됐습니다. 브라우저 작업에는 무언가를 실행하는 단계뿐 아니라 다음 단계로 넘어가기 전에 대기하는 단계도 필요합니다. 다만 이번 커밋 정보만으로는 어떤 조건을 기준으로 기다리는지, 파일과 표를 어디까지 지원하는지 알 수 없습니다. 기능이 추가됐다는 사실과 세부 동작이 검증됐다는 판단은 구분해 두려고 합니다.

## 위험한 작업은 권한 모드와 관계없이 매번 확인하기

desktop 영역에서는 공격 도구, 수집 주소, 역방향 셸에 대해 어떤 권한 모드에서도 매번 묻도록 했습니다. 이번 변경의 핵심은 확인 여부가 권한 모드에 따라 달라지지 않는다는 점입니다.

권한 모드를 선택해 두었더라도 이 세 범주에 해당하는 작업은 확인을 건너뛰지 않습니다. 사용자는 해당 작업이 나올 때마다 판단해야 하므로 확인 부담이 생길 수 있습니다. 대신 이 범주에서는 편의보다 개별 확인을 우선한다는 경계가 분명해졌습니다.

여기서 ‘묻는다’는 동작을 ‘차단한다’는 뜻으로 읽지는 않아야 합니다. 커밋에서 확인할 수 있는 것은 매번 확인을 요청한다는 정책입니다. 공격 도구나 수집 주소를 어떤 기준으로 판별하는지, 확인 이후에 어떤 처리를 하는지는 제공된 정보만으로 설명하기 어렵습니다.

## Windows 설정에서 Aside와 Ego 안내하기

Windows 설정에는 Aside를 알아보고 Ego 설치를 안내하는 변경이 들어갔습니다. 설정 화면에서 Aside를 인식하는 부분과 Ego 설치 안내를 함께 다룬 작업입니다.

이 변경은 앞의 브라우저 기능 확장과는 성격이 다릅니다. 브라우저에서 수행할 작업을 추가했다면, 여기서는 Windows 환경을 설정할 때 필요한 안내를 보강했습니다. 다만 설치를 ‘안내’한다는 범위를 넘어 자동 설치까지 지원한다고 볼 근거는 없습니다. Aside와 Ego의 구체적인 관계나 지원 조건도 이번 기록에는 덧붙이지 않겠습니다.

## 브라우저 단계와 공격 탐지 분석을 문서로 남기기

vibe 문서에는 브라우저 3단계와 에이전트 공격 탐지 분석을 기록했습니다. 브라우저 작업과 공격 관련 권한 확인을 구현한 변경 옆에, 관련 분석을 문서로 남긴 변경도 포함된 것입니다.

분석 기록과 구현 결과는 나눠서 봐야 합니다. 문서에 공격 탐지 분석을 남겼다는 사실만으로 탐지 기능이 완성됐거나 효과가 검증됐다고 말할 수는 없습니다. 브라우저 3단계 역시 각 단계의 내용은 커밋 정보에 드러나지 않습니다.

이번 변경에서 확인되는 방향은 구체적입니다. 브라우저에는 파일·대기·표 작업을 추가했고, 데스크톱에서는 특정 위험 범주에 대한 확인을 권한 모드와 무관하게 유지했습니다. Windows 설정 안내와 분석 문서도 함께 보강했습니다. 지원 범위와 판별 기준 같은 세부 사항은 실제 구현과 문서를 확인하며 이어서 살펴볼 부분으로 남겨 둡니다.
